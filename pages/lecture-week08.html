1. 평가 개요

1.1 시험 운영

항목내용
평가명직무수행능력평가 1차 (중간고사)
평가 범위1~7주차 강의교안 본문과 수업 중 실습 내용
문항 구성객관식 + 주관식 (비율 미정)
시험 시간60분 (8주차 정규 수업 시간 중 실시)
성적 반영30점 만점으로 전체 성적의 30%에 그대로 반영 · 개인별 평가 · 소수점은 반올림하지 않고 버림

1.2 문항 유형

구분출제 형태
객관식 • 옳은 것 / 옳지 않은 것 고르기
• 보기(ㄱ·ㄴ·ㄷ…) 중 옳은 것만을 있는 대로 고르기
• 개념–설명, 상황–대응 방법을 옳게 짝짓기
• 사례를 읽고 적절한 개념·절차·AI 활용 방식 판단하기
주관식 • 두 개념의 차이를 비교해 설명하기
• 주어진 사례를 진단하고 개선안 제시하기
• 수업에서 다룬 절차를 새로운 상황에 순서대로 적용하기
• 여러 주차의 개념을 연결해 근거 있게 서술하기

2. 주차별 학습 가이드

암기보다 중요한 구분

구분해야 할 개념핵심 질문
검색과 생성원문을 찾아 주는 것과 답을 구성해 주는 것은 사용자의 역할·장점·한계가 어떻게 다른가?
생성형 AI와 에이전트형 AI한 번의 요청–응답과 목표 기반 다단계 작업은 사람의 역할이 어떻게 달라지는가?
모델과 서비스결과가 다를 때 모델의 한계인지 서비스 기능의 한계인지 어떻게 판단하는가?
프롬프트와 지침한 번의 요청을 잘 전달하는 것과 반복 조건을 맞춤형 AI에 고정하는 것은 무엇이 다른가?
일반 대화와 프로젝트언제 새 대화창을 열고, 언제 프로젝트 공간에서 맥락을 이어가야 하는가?
생성과 검증AI가 만든 결과에서 무엇을 검증 대상으로 고르고, 어떤 순서로 확인하는가?
단일 모달과 멀티모달여러 형태를 다루는 것과 형태 사이의 의미를 연결하는 것은 어떻게 다른가?
문제와 해결책문제 문장에 해결책이 섞이면 어떤 문제가 생기는가?
도구 선택과 도구 암기도구 이름을 아는 것보다 작업 목적에 맞는 도구를 고르는 근거를 설명할 수 있는가?

3. 답안 작성 기준

4.1 객관식 풀이 원칙

- 발문의 “옳은 것 / 옳지 않은 것 / 있는 대로 고른 것”을 끝까지 확인

- 보기 문장은 앞부분만 보지 말고 결론·대응 방법·범위를 나타내는 표현까지 끝까지 읽음

- “모두 고르기” 문항은 보기 하나하나를 옳음·틀림으로 따로 판정한 뒤 조합을 고름

- “항상”, “유일한”, “예외 없이”처럼 범위를 단정하는 표현은 교안의 원칙과 대조해 판단

4.2 주관식 작성 기준

기준좋은 답안약한 답안
개념 정확성교안 용어를 구분해 정확히 사용함AI 관련 용어를 비슷한 뜻으로 섞어 씀
근거왜 그런 판단을 했는지 이유가 있음좋다·편하다 수준으로 끝남
적용주어진 사례와 개념을 연결함교안 문장을 그대로 외워 씀
위험 인식검증·개인정보·저작권·책임을 함께 고려함AI가 해 준다는 사실만 설명함
요구 충족문항이 요구한 개수·관점·순서를 모두 지킴요구한 관점 일부를 빠뜨리거나 개수를 채우지 않음
