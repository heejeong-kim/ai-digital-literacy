	1. 특정 AI 서비스의 메뉴를 빠르게 찾는 능력
	2. AI 결과가 만들어지는 특성과 한계를 이해하고 검증·책임까지 판단하는 능력
	3. 문서 편집과 파일 저장을 능숙하게 수행하는 능력
	4. 새로운 앱을 설치하고 계정을 생성하는 능력
	### 2. \[확장형·1주차\]
	UNESCO의 AI 역량 프레임워크에서 학습자가 AI를 단순히 사용하는 수준을 넘어 비판적으로 평가할 때 가장 관련이 깊은 태도는?
	1. AI 결과를 권위 있는 답으로 간주한다
	2. 인간의 판단과 책임을 유지하며 AI의 사회적 영향을 검토한다
	3. 가장 최신 모델만 선택한다
	4. 출력 속도를 성능의 핵심 기준으로 삼는다
	### 3. \[교안형·2주차\]
	학습 데이터에서는 성능이 매우 높지만 새로운 데이터에서는 성능이 크게 낮아지는 모델의 상태를 가장 잘 설명한 것은?

	2. 과적합
	3. 군집화
	4. 정규화
	### 4. \[확장형·2주차\]
	모델 개발 과정에서 **데이터 누수(data leakage)**가 발생한 사례로 가장 적절한 것은?
	1. 훈련 데이터와 시험 데이터를 서로 다른 파일에 저장했다
	2. 예측 시점 이후에만 알 수 있는 정보를 학습 특징에 포함했다
	3. 결측치를 별도 값으로 표시했다
	4. 범주형 변수를 숫자로 변환했다
	### 5. \[교안형·3주차\]
	검색 결과의 신뢰도를 평가할 때 가장 적절한 순서는?
	1. 조회 수 확인 → 제목 확인 → 댓글 확인
	2. 작성자·기관 확인 → 근거 원자료 확인 → 최신성·맥락 확인 → 독립 자료 교차검증
	3. 검색 순위 확인 → 광고 여부 확인 → 첫 결과 사용
	4. AI에게 요약 요청 → 요약 내용만 비교
	### 6. \[확장형·3주차\]

	1. 같은 주장을 반복하는 사이트를 많이 찾는다
	2. 주장·인용·이미지가 처음 나온 원출처와 원래 맥락을 추적한다
	3. 검색 결과 첫 페이지에 있는 자료만 사용한다
	4. SNS 공유 횟수를 확인한다
	### 7. \[교안형·4주차\]
	한 제조기업이 AI로 불량 후보를 표시하고 최종 불량 판정은 작업자가 수행하도록 설계했다. 이 구조의 핵심 장점으로 가장 적절한 것은?
	1. 인간의 책임을 완전히 제거한다
	2. AI의 탐지 속도와 인간의 맥락 판단을 결합한다
	3. 데이터 품질 검토가 필요 없어진다
	4. 모든 예외 상황을 자동 처리한다
	### 8. \[확장형·4주차\]

	1. 전자는 사람이 개별 의사결정 과정에 직접 참여하고, 후자는 자동 시스템을 감독하며 필요 시 개입한다
	2. 전자는 데이터 없이 작동하고 후자는 데이터로 작동한다
	3. 전자는 생성형 AI, 후자는 판별형 AI에만 사용한다
	4. 두 구조는 책임 배분 측면에서 차이가 없다
	### 9. \[교안형·5주차\]
	프롬프트에 목적·대상·자료·출력 형식을 모두 명시했음에도 결과가 기대와 다르다. 가장 적절한 다음 행동은?

	3. 역할을 무조건 더 전문적으로 바꾼다
	4. 조건을 모두 삭제한다
