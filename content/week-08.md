# 2. 문항을 풀 때 확인할 것
1. **개념의 정의보다 역할을 이해하기:** 어떤 상황에서 사용하는 개념인지 확인
2. **비슷한 개념의 차이 구분하기:** 데이터와 정보, 얼굴 검출과 얼굴 인식, 1차 자료와 2차 자료, 피싱과 일반 홍보 메시지
3. **사람의 역할 확인하기:** AI가 결과를 만든 사실과 최종 판단을 누가 하는지 구분
4. **수치와 그래프의 조건 확인하기:** 평균·비율·표본·축·단위·기간을 함께 확인
5. **보안·윤리 문항은 행동 기준으로 판단하기:** 링크 클릭 여부, 공식 경로 재확인, 필요한 정보만 사용, 타인의 권리와 공개 범위 고려
