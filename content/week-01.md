# 1️⃣ 1교시 \| AI의 개념과 기본 이해
## 1. 인공지능(Artificial Intelligence)이란 무엇인가
인공지능은 컴퓨터가 인간의 지적 활동과 유사한 과제를 수행하도록 만드는 기술과 방법의 집합
핵심은 AI를 사람처럼 생각하는 존재로 보는 것이 아니라 **주어진 목적에 따라 데이터를 처리하고 패턴을 이용해 결과를 만드는 시스템**으로 이해하는 것
### 1.1 AI를 이해하는 기본 관점
AI는 스스로 목적을 정하는 존재가 아니라 사람이 정한 문제와 목적 안에서 입력을 처리하고 결과를 산출하는 시스템
- **목적**: 무엇을 해결하려는지에 대한 기준
- **입력**: AI가 처리할 텍스트·이미지·음성·숫자 등의 데이터
- **처리**: 학습된 패턴과 계산 구조를 이용한 분석
- **결과**: 분류·예측·추천·생성 등의 형태로 제공되는 산출물
- **예시**: 번역 AI의 목적은 언어 변환, 입력은 원문 문장, 처리 과정은 학습된 언어 패턴을 이용한 계산, 결과는 번역된 문장
- **이해 포인트**: 자연스러운 문장이나 정교한 이미지가 곧 사람과 같은 이해를 의미하는 것은 아님
- **핵심**: AI의 출력은 정해진 목적과 학습된 패턴을 바탕으로 만들어진 계산 결과
---
### 1.2 좁은 인공지능(Narrow AI)
현재 상용 서비스에서 사용하는 대부분의 AI는 특정 과제에 특화된 좁은 인공지능
하나의 시스템이 모든 문제를 해결하는 것이 아니라 정해진 과제에서 높은 성능을 보이도록 설계된 형태
- **번역 AI**: 언어 변환에 특화
- **추천 AI**: 사용자의 선택 가능성 예측에 특화
- **얼굴 인식 AI**: 이미지 속 얼굴 특징 식별에 특화
- **수요 예측 AI**: 과거 판매 패턴을 이용한 미래 수요 추정에 특화
- **이미지 생성 AI**: 텍스트 지시를 바탕으로 새로운 시각 콘텐츠 구성에 특화
- **예시 \| 내비게이션**: 현재 위치·목적지·교통량·이동 기록을 입력으로 받아 도착시간을 예측
- **강점**: 많은 교통 데이터를 빠르게 비교해 이동시간 추정
- **범위**: 문서 요약이나 이미지 생성처럼 다른 종류의 과제 수행과는 별개
- **핵심**: 정해진 목적과 과제 범위 안에서의 전문화
---
### 1.3 범용 인공지능(Artificial General Intelligence)
범용 인공지능은 특정 과제 하나에 한정되지 않고 서로 다른 종류의 문제를 폭넓게 이해하고 학습하며 해결하는 개념
현재 일반적으로 사용하는 상용 AI와는 개념적으로 구분
- **좁은 인공지능**: 특정 과제 중심
- **범용 인공지능**: 다양한 과제와 상황을 폭넓게 다루는 개념
- **현재 상용 AI**: 대부분 좁은 인공지능에 해당
- **비유**: 좁은 인공지능이 특정 업무를 잘하는 전문 도구라면 범용 인공지능은 서로 다른 문제 사이에서 지식과 판단을 폭넓게 연결하는 지능을 가정한 개념
- **이해 포인트**: ‘AI’라는 하나의 이름 아래 서로 다른 수준과 목적의 시스템이 존재
<callout icon="💡" color="green_bg">
	**핵심 이해**
	현재 우리가 사용하는 대부분의 AI는 특정 목적과 기능에 맞춰 설계된 좁은 인공지능
</callout>
## 2. 인공지능의 대표 기능
AI는 하나의 기능만 수행하는 기술이 아니라 여러 기능을 조합해 서비스에 활용하는 구조
같은 서비스 안에서도 인식·분류·예측·추천·생성 기능의 동시 활용 가능
### 2.1 인식(Recognition)
인식은 이미지·음성·문자·센서 신호처럼 복잡한 입력에서 의미 있는 대상을 찾아내는 기능
사람이 사진 속 사람이나 사물을 알아보는 것과 비슷하게 AI가 입력 데이터에서 특정 특징을 찾아내는 단계
- **주요 입력**: 이미지, 음성, 문자, 영상, 센서 신호
- **대표 활용**: 얼굴 위치 탐지, 음성에서 발화 내용 추출, 문서 이미지에서 문자 추출, 공장 영상에서 제품 위치 탐지
- **예시 \| 스마트폰 카메라**: 사진 속 얼굴 영역을 찾아 자동으로 초점을 맞추는 기능
- **연결 구조**: 인식 결과가 분류·예측·추천의 입력으로 활용되는 경우가 많음
- **이해 포인트**: 인식은 ‘무엇이 있는지 찾아내는 기능’에 가까우며 이후 판단 단계와 구분
---
### 2.2 분류(Classification)
분류는 입력을 미리 정한 범주 중 하나 또는 여러 범주로 나누는 기능
핵심은 **결과의 범주가 사전에 정해져 있다는 점**
- **대표 활용**: 이메일 → 스팸/정상, 제품 이미지 → 불량/정상, 고객 문의 → 배송/결제/환불/기타, 뉴스 기사 → 정치/경제/문화/스포츠
- **입력 특징**: 텍스트·이미지·수치 등 다양한 형태 가능
- **예시 \| 스팸메일**: 이메일 제목·본문·링크·발신 패턴을 분석해 스팸 또는 정상 메일로 분류
- **오류 가능성**: 정상 메일이 스팸으로 분류되거나 스팸이 통과하는 상황
- **이해 포인트**: 분류는 결과 범주뿐 아니라 어떤 오류가 발생할 수 있는지도 함께 확인할 필요
---
### 2.3 예측(Prediction)
예측은 과거와 현재 데이터를 이용해 미래의 값이나 사건의 가능성을 추정하는 기능
정답을 미리 알고 계산하는 것이 아니라 과거에 반복된 패턴을 바탕으로 앞으로 일어날 가능성을 계산하는 방식
- **대표 활용**: 판매 수요 예측, 고객 이탈 가능성 예측, 기계 고장 가능성 예측, 도착시간 예측, 대출 연체 가능성 예측
- **주요 데이터**: 과거 기록, 현재 상태, 계절·시간·환경 정보
- **예시 \| 쇼핑몰 수요예측**: 과거 판매량·계절·행사·가격 변화 등을 분석해 다음 달 상품별 판매량을 추정
- **활용 목적**: 재고 준비, 인력 배치, 위험 관리, 운영 계획
- **이해 포인트**: 예측값은 확정된 미래가 아니라 현재 데이터와 과거 패턴을 바탕으로 계산한 가능성
- **주의점**: 예상하지 못한 사건이나 환경 변화가 발생하면 예측 성능 변화 가능
---
### 2.4 추천(Recommendation)
추천은 사용자의 행동·선호·유사 사용자 정보를 이용해 선택 가능성이 높은 항목을 제시하는 기능
모든 선택지를 보여주는 대신 관심 가능성이 높은 후보를 우선 제시하는 방식
- **대표 활용**: 온라인 쇼핑 상품 추천, 동영상 추천, 음악 추천, 뉴스·콘텐츠 추천, 온라인 강의 추천
- **사용 데이터**: 시청 기록, 검색 기록, 클릭, 구매, 재생 시간, 유사 사용자의 행동
- **예시 \| 동영상 플랫폼**: 사용자의 시청 기록과 비슷한 이용자의 행동을 분석해 다음에 볼 가능성이 높은 영상을 추천
- **결과 특징**: 서비스가 정한 목표와 사용자 데이터에 따라 달라지는 개인화된 결과
- **이해 포인트**: 같은 플랫폼에서도 사용자마다 화면에 보이는 콘텐츠가 달라질 수 있음
- **주의점**: 추천 결과가 전체 선택지의 객관적 순위를 의미하는 것은 아님
---
### 2.5 생성(Generation)
생성은 학습한 패턴을 바탕으로 새로운 텍스트·이미지·음성·영상·코드 등을 구성하는 기능
기존 자료를 그대로 검색해 보여주는 방식과 달리 입력된 요청과 학습된 패턴을 조합해 새로운 출력 생성
- **대표 활용**: 보고서 초안, 이미지 생성, 음성 합성, 영상 장면 생성, 프로그래밍 코드 생성
- **입력 형태**: 질문, 지시문, 이미지, 음성, 여러 형식의 결합
- **예시 \| 강의 소개문**: `대학생 대상 AI 입문 강의 소개문을 작성해줘`라는 요청에 새로운 소개문 생성
- **장점**: 초안 제작, 아이디어 확장, 반복 작업 단축
- **주의점**: 자연스럽고 완성도 높게 보이는 결과가 사실성·출처·맥락까지 자동으로 보장하는 것은 아님
- **이해 포인트**: 생성은 콘텐츠 제작 기능과 결과 검토가 함께 필요한 영역
---
### 2.6 의사결정 지원(Decision Support)
의사결정 지원은 AI가 최종 결정을 대신하기보다 점수·위험 신호·후보·요약 등을 제공해 사람의 판단을 돕는 기능
AI의 계산 능력과 사람의 맥락 판단을 결합하는 형태
- **대표 활용**: 의료 영상에서 의심 부위 표시, 금융 거래 이상 신호 표시, 고객 이탈 위험 점수, 우선 검토 대상 추천
- **예시 \| 카드 이상거래 탐지**: 결제 패턴을 분석해 이상거래 가능성이 높은 거래에 위험 신호 표시
- **AI의 역할**: 대량 데이터 분석, 위험 후보 선별, 우선순위 제안
- **사람의 역할**: 맥락 확인, 추가 정보 검토, 최종 판단
- **이해 포인트**: 중요한 결정에서는 AI의 결과와 최종 의사결정을 구분할 필요
## 3. AI는 어떻게 결과를 만드는가
AI를 처음 이해할 때 복잡한 수식보다 **입력 → 처리 → 결과**의 큰 흐름을 먼저 이해하는 것이 핵심
### 3.1 입력(Input)
입력은 AI가 처리할 대상이 들어오는 단계
어떤 입력을 받는지에 따라 AI가 수행할 수 있는 과제와 결과의 형태도 달라지는 구조
- **텍스트**: 질문, 문서, 이메일, 검색어
- **이미지**: 사진, 스캔 문서, 의료 영상
- **음성**: 사람의 말, 통화 녹음, 음성 명령
- **숫자**: 매출, 온도, 센서값, 거래 금액
- **행동 기록**: 클릭, 구매, 시청, 검색 기록
- **예시 \| 번역 AI**: 사용자가 입력한 한국어 문장이 입력 데이터
- **이해 포인트**: 입력의 내용과 품질이 결과에 직접적인 영향
---
### 3.2 처리(Process)
처리는 학습된 모델이 입력 데이터의 특징과 패턴을 바탕으로 계산을 수행하는 단계
사람이 모든 규칙을 직접 지정하지 않아도 모델이 학습한 패턴을 이용해 결과 후보를 계산하는 과정
- **특징 파악**: 입력에서 의미 있는 요소 추출
- **패턴 비교**: 학습 과정에서 익힌 패턴과 현재 입력 비교
- **계산**: 가장 관련 있는 범주·값·후보·문장 등을 계산
- **예시 \| 스팸메일**: 단어, 링크, 발신자 패턴, 표현 방식 등을 분석
- **이해 포인트**: 사용자는 처리 과정 전체를 직접 보지 못하는 경우가 많지만 결과는 이 계산 과정의 산출물
---
### 3.3 결과(Output)
결과는 AI가 계산한 내용을 사용자에게 제공하는 단계
같은 입력이라도 모델의 종류와 목적에 따라 서로 다른 형태의 결과 가능
- **분류 결과**: 스팸/정상, 불량/정상
- **예측값**: 예상 판매량, 도착시간, 위험 점수
- **추천 목록**: 상품, 영상, 음악, 콘텐츠
- **생성 결과**: 문장, 이미지, 음성, 코드
- **예시 \| 스팸메일**: 이메일을 스팸 또는 정상으로 표시
- **이해 포인트**: 결과는 ‘컴퓨터가 생각한 정답’이 아니라 데이터와 학습된 패턴을 바탕으로 계산된 산출물
<callout icon="💡" color="green_bg">
	**기본 흐름**
	입력 → 모델을 통한 처리 → 결과
</callout>
## 4. 데이터(Data)·알고리즘(Algorithm)·모델(Model)의 관계
AI가 결과를 만드는 구조를 이해하기 위한 세 가지 기본 요소
세 요소는 서로 독립된 개념이 아니라 하나의 학습·활용 흐름 안에서 연결
### 4.1 데이터(Data)
데이터는 AI가 학습하거나 결과를 만들 때 사용하는 재료
AI가 어떤 데이터를 접했는지에 따라 학습되는 패턴과 결과의 범위도 달라질 수 있음
- **형태**: 텍스트, 이미지, 음성, 숫자, 행동 기록, 센서 정보
- **역할**: 반복되는 특징과 패턴을 학습하기 위한 재료
- **예시 \| 상품 추천**: 사용자의 검색·클릭·구매 기록이 추천을 위한 데이터
- **예시 \| 이미지 분류**: 다양한 고양이와 강아지 이미지가 학습 데이터
- **이해 포인트**: 데이터가 부족하거나 한쪽 상황에 치우치면 모델이 다양한 상황을 충분히 반영하기 어려울 수 있음
---
### 4.2 알고리즘(Algorithm)
알고리즘은 문제를 해결하기 위한 계산 절차와 방법
AI 학습에서는 데이터를 어떤 방식으로 처리하고 모델의 내부 값을 어떻게 조정할지 결정하는 역할
- **역할 1 \| 처리 방법**: 데이터를 어떤 순서와 방식으로 계산할지 결정
- **역할 2 \| 학습 방법**: 모델의 예측과 실제 결과의 차이를 줄이도록 내부 값을 조정하는 방법 제공
- **역할 3 \| 최적화**: 반복 학습을 통해 더 나은 결과를 만들 수 있도록 계산 과정 조정
- **예시 \| 이미지 분류**: 많은 이미지에서 특징을 비교하고 분류 오류가 줄어들도록 모델을 반복 조정
- **비유**: 데이터가 학습 재료라면 알고리즘은 그 재료를 이용해 학습하는 방법
- **이해 포인트**: 알고리즘 자체가 최종 결과를 저장하는 것이 아니라 모델을 학습시키는 방법에 가까운 개념
---
### 4.3 모델(Model)
모델은 데이터를 이용한 학습의 결과로 만들어진 계산 구조
새로운 입력이 들어왔을 때 분류·예측·추천·생성 등의 실제 결과를 만드는 핵심 요소
- **생성 과정**: 데이터와 알고리즘을 이용한 학습을 통해 형성
- **역할**: 새로운 입력을 받아 학습된 패턴에 따라 결과 계산
- **활용 형태**: 분류 모델, 예측 모델, 추천 모델, 생성 모델 등
- **예시 \| 스팸 분류 모델**: 새로운 이메일이 들어오면 학습한 패턴을 이용해 스팸 가능성 계산
- **예시 \| 생성형 AI 모델**: 사용자의 질문을 받아 다음에 올 가능성이 높은 표현을 바탕으로 문장 생성
- **이해 포인트**: 같은 종류의 AI라도 학습 데이터와 학습 방식이 다르면 서로 다른 모델과 결과 가능
---
### 4.4 데이터·알고리즘·모델의 연결
세 요소는 AI가 학습되고 실제로 사용되는 과정을 하나의 흐름으로 연결하는 핵심 개념
- **1단계 \| 데이터 준비**: 학습에 사용할 텍스트·이미지·숫자 등의 자료 준비
- **2단계 \| 알고리즘 적용**: 데이터를 이용해 모델의 내부 값을 조정
- **3단계 \| 모델 생성**: 반복 학습을 통해 문제 해결에 사용할 계산 구조 형성
- **4단계 \| 새로운 입력**: 실제 사용자 데이터 입력
- **5단계 \| 결과 생성**: 학습된 모델이 분류·예측·추천·생성 결과 제공
- **전체 흐름**: 데이터 → 알고리즘을 이용한 학습 → 모델 → 새로운 입력 → 결과
- **쉬운 비유**: 데이터 = 연습문제와 사례 / 알고리즘 = 학습하는 방법 / 모델 = 학습을 통해 만들어진 문제 해결 방식
- **이해 포인트**: AI 결과를 이해하려면 결과만 보는 것이 아니라 어떤 데이터와 학습 과정을 거쳐 만들어진 모델인지 함께 보는 관점 필요
## 5. AI가 잘하는 일과 사람이 맡아야 하는 일
AI의 강점과 사람의 역할을 구분하면 AI를 과도하게 기대하거나 필요 이상으로 두려워하는 태도에서 벗어나기 쉬운 구조
### 5.1 AI가 잘하는 일
AI는 많은 데이터를 빠르게 처리하고 반복되는 패턴을 찾는 작업에 강점
- **대량 처리**: 많은 문서·이미지·거래 기록을 빠르게 처리
- **패턴 탐색**: 반복적으로 나타나는 특징과 관계 탐색
- **분류·예측**: 일정한 기준을 바탕으로 범주나 가능성 계산
- **추천**: 사용자 데이터에 기반한 후보 제안
- **생성**: 문장·이미지·아이디어·코드의 초안 제작
- **반복 작업**: 일정한 형식의 정리·요약·변환 지원
- **예시**: 수천 건의 고객 문의를 유형별로 분류하고 주요 내용을 요약
- **이해 포인트**: 많은 양을 빠르게 처리하는 능력과 최종 판단 능력은 서로 다른 개념
---
### 5.2 사람이 맡아야 하는 일
사람은 문제의 목적과 기준을 정하고 AI 결과를 실제 상황에 맞게 해석하는 역할에서 중요
- **목적 설정**: 무엇을 해결할 것인지 결정
- **우선순위 결정**: 어떤 기준이 더 중요한지 판단
- **맥락 해석**: 예외 상황과 사회적·문화적 맥락 이해
- **검토**: 사실·권리·윤리·개인정보 문제 확인
- **최종 승인**: 결과를 실제로 사용할지 결정
- **책임**: 중요한 의사결정의 결과에 대한 책임
- **예시**: AI가 의료 영상의 의심 부위를 표시하더라도 최종 진단과 치료 결정은 의료진의 검토 필요
- **이해 포인트**: AI가 결과를 제시할 수 있다는 사실과 그 결과를 그대로 사용해도 된다는 의미는 별개
---
### 5.3 AI와 사람의 협업
AI와 사람의 관계는 한쪽이 다른 쪽을 완전히 대체하는 구조보다 서로 다른 강점을 결합하는 구조로 이해하는 것이 적절
- **AI 역할**: 대량 처리, 패턴 탐색, 후보 생성, 초안 작성
- **사람 역할**: 목적 설정, 질문 설계, 결과 검토, 맥락 판단, 최종 책임
- **예시 \| 보고서 작성**: AI가 자료 요약과 초안을 생성하고 사람이 사실 확인·구조 수정·최종 편집
- **예시 \| 고객 상담**: AI가 문의 유형을 분류하고 답변 초안을 제안하며 상담원이 예외 상황과 감정적 맥락을 판단
- **핵심 연결**: AI 결과를 이해하고 확인하고 판단하는 역량의 필요
- **다음 교시 연결**: 이 지점에서 필요한 개념이 디지털 리터러시와 AI 리터러시
# 2️⃣ 2교시 \| 디지털 리터러시와 AI 시대의 인간 역량
## 1. 디지털 리터러시(Digital Literacy)란 무엇인가
디지털 리터러시는 스마트폰이나 컴퓨터를 능숙하게 사용하는 기술만을 의미하는 개념이 아님
핵심은 **디지털 환경에서 정보를 찾고, 이해하고, 판단하고, 만들고, 소통하며, 안전하고 책임 있게 활용하는 종합적인 역량**
### 1.1 단순한 디지털 활용과의 차이
디지털 도구를 사용할 줄 아는 능력과 디지털 환경에서 정보를 판단하고 책임 있게 활용하는 능력은 서로 다른 수준
- **도구 활용**: 앱 설치, 문서 작성, 검색 기능 사용, 파일 공유
- **정보 판단**: 검색 결과의 출처와 신뢰성 확인
- **책임 있는 활용**: 개인정보, 저작권, 타인의 권리 고려
- **콘텐츠 제작**: 목적과 대상에 맞는 디지털 콘텐츠 구성
- **예시**: 검색창에 원하는 키워드를 입력하는 것은 도구 활용, 검색 결과 중 무엇을 믿을지 판단하는 것은 디지털 리터러시
- **이해 포인트**: ‘잘 쓴다’와 ‘잘 판단한다’는 서로 다른 능력
---
### 1.2 디지털 리터러시의 핵심 의미
디지털 리터러시는 디지털 환경에서 필요한 정보를 선택하고 의미를 해석하며 책임 있게 행동하기 위한 종합 능력
- **찾기**: 필요한 정보를 효율적으로 검색
- **이해**: 정보의 의미와 맥락 파악
- **판단**: 출처·근거·편향·오류 가능성 확인
- **생성**: 목적에 맞는 콘텐츠 제작
- **소통**: 디지털 공간에서 적절하게 의견 교환
- **책임**: 개인정보·저작권·안전·윤리 고려
- **예시**: 온라인 기사 하나를 읽을 때 제목만 보는 것이 아니라 출처·작성 시점·근거 자료까지 확인
- **이해 포인트**: 디지털 리터러시는 기술 사용 능력과 비판적 판단 능력의 결합
## 2. 왜 디지털 리터러시가 필요한가
디지털 환경에서는 정보의 양과 생성 속도가 매우 빠르며 사용자가 접하는 정보의 순서도 플랫폼과 알고리즘의 영향을 받는 구조
### 2.1 정보의 양과 속도의 증가
온라인에서는 누구나 빠르게 정보를 만들고 공유할 수 있기 때문에 필요한 정보를 찾는 것뿐 아니라 무엇을 믿을지 판단하는 능력도 중요
- **환경 변화**: 뉴스, 블로그, SNS, 동영상, 커뮤니티 등 정보 채널의 증가
- **특징**: 같은 사건에 대해 서로 다른 설명과 해석이 동시에 존재
- **위험 요소**: 오래된 정보, 잘못된 정보, 과장된 정보, 맥락이 빠진 정보
- **예시**: SNS에서 빠르게 확산된 건강 정보가 실제 의학적 근거와 다를 수 있는 상황
- **이해 포인트**: 정보가 많아질수록 검색 능력보다 선택과 판단 능력의 중요성 증가
---
### 2.2 알고리즘이 정보 선택에 미치는 영향
디지털 플랫폼은 사용자의 관심과 행동을 바탕으로 보여줄 콘텐츠를 자동으로 선택하는 경우가 많음
- **사용 데이터**: 클릭, 시청 시간, 검색 기록, 좋아요, 구매 기록
- **작동 방식**: 사용자가 볼 가능성이 높은 콘텐츠를 우선 노출
- **장점**: 많은 정보 중 관심 가능성이 높은 콘텐츠를 빠르게 발견
- **한계**: 사용자가 전체 정보를 균형 있게 보는 것이 아니라 특정 기준으로 선택된 정보만 반복적으로 접할 가능성
- **예시**: 같은 뉴스 플랫폼을 사용해도 사용자마다 추천 기사 목록이 다른 상황
- **이해 포인트**: 화면에 보이는 정보가 전체 정보의 객관적 목록이라는 가정은 부적절
---
### 2.3 생성형 AI의 등장
생성형 AI는 텍스트·이미지·음성·영상 등을 빠르게 만들 수 있어 디지털 콘텐츠 생산의 속도와 규모를 크게 확대
- **변화**: 전문 제작 도구 없이도 누구나 고품질 콘텐츠 생성 가능
- **장점**: 초안 작성, 아이디어 확장, 시각 자료 제작, 반복 작업 단축
- **위험 요소**: 사실과 다른 내용, 존재하지 않는 출처, 조작 이미지, 잘못된 맥락
- **예시**: AI가 만든 자연스러운 보고서 문장 안에 사실과 다른 수치가 포함된 상황
- **이해 포인트**: 콘텐츠의 자연스러움과 정보의 정확성은 서로 다른 문제
## 3. 디지털 리터러시의 기본 구성
디지털 리터러시는 하나의 능력이 아니라 여러 역량의 결합
각 역량은 실제 디지털 활동에서 서로 연결되어 작동
### 3.1 정보 탐색
정보 탐색은 필요한 정보를 효과적으로 찾고 적절한 검색 전략을 사용하는 능력
- **키워드 설정**: 너무 넓거나 모호한 표현보다 구체적 검색어 사용
- **검색 범위 조정**: 기간, 출처, 자료 유형 등을 조절
- **여러 출처 비교**: 하나의 결과만 보지 않고 여러 자료 확인
- **예시**: ‘AI 문제’보다 ‘생성형 AI 대학 교육 활용 사례’처럼 검색 목적을 구체화
- **이해 포인트**: 좋은 검색 결과는 좋은 질문과 검색어에서 시작
---
### 3.2 정보 이해
정보 이해는 찾은 자료의 내용과 맥락을 정확하게 파악하는 능력
- **핵심 내용 파악**: 자료가 무엇을 주장하는지 확인
- **맥락 확인**: 언제, 어디서, 어떤 목적으로 만들어진 자료인지 확인
- **용어 이해**: 전문용어와 핵심 개념의 의미 확인
- **예시**: 통계 수치만 보는 것이 아니라 조사 대상·기간·방법까지 확인
- **이해 포인트**: 정보의 일부만 떼어 보면 원래 의미와 다른 해석 가능
---
### 3.3 정보 판단
정보 판단은 자료의 출처·근거·신뢰성·편향 가능성을 검토하는 능력
- **출처 확인**: 누가 만들었는지 확인
- **근거 확인**: 주장에 어떤 자료와 증거가 사용됐는지 확인
- **교차 검증**: 다른 신뢰할 수 있는 자료와 비교
- **작성 시점 확인**: 오래된 정보인지 최신 정보인지 확인
- **예시**: SNS 게시물의 주장과 정부·학술기관·언론의 원자료 비교
- **이해 포인트**: 많이 공유된 정보와 신뢰할 수 있는 정보는 동일하지 않음
---
### 3.4 콘텐츠 생성
콘텐츠 생성은 목적과 대상에 맞게 텍스트·이미지·영상·자료를 구성하는 능력
- **목적 설정**: 설명, 설득, 기록, 홍보 등 목적 결정
- **대상 고려**: 연령, 배경지식, 관심 수준에 맞는 표현 선택
- **형식 선택**: 문서, 이미지, 영상, 발표자료 등 적절한 형식 결정
- **출처 표시**: 다른 사람의 자료와 아이디어를 사용할 때 출처와 권리 확인
- **예시**: 같은 AI 개념을 초등학생용 카드뉴스와 대학생용 발표자료로 다르게 구성
- **이해 포인트**: 좋은 콘텐츠는 단순히 보기 좋은 결과보다 목적·대상·근거가 명확한 결과
---
### 3.5 디지털 소통
디지털 소통은 온라인 공간에서 다른 사람과 정보를 주고받고 협업하는 능력
- **표현 방식**: 상대와 상황에 맞는 언어 사용
- **맥락 이해**: 문자 기반 소통에서 오해 가능성 고려
- **협업**: 공동 문서, 메신저, 프로젝트 도구 등을 활용한 협력
- **기록 관리**: 공개·비공개 범위와 남는 기록 고려
- **예시**: 단체 채팅방에서 개인 정보를 공개하지 않고 필요한 정보만 공유
- **이해 포인트**: 디지털 공간의 소통도 현실의 관계와 책임에서 분리되지 않음
---
### 3.6 안전과 책임
안전과 책임은 디지털 활동에서 개인정보·저작권·보안·윤리를 고려하는 능력
- **개인정보**: 주민번호, 연락처, 위치, 계정정보 등 민감한 정보 보호
- **저작권**: 이미지·음악·문서·영상의 사용 권한 확인
- **보안**: 비밀번호, 피싱, 악성 링크, 계정 탈취 위험 관리
- **책임**: 다른 사람에게 미칠 영향과 공개 범위 고려
- **예시**: 생성형 AI에 회사 내부 문서나 타인의 개인정보를 그대로 입력하지 않는 판단
- **이해 포인트**: 편리함보다 먼저 확인해야 할 영역이 존재
## 4. 인공지능 리터러시(AI Literacy)란 무엇인가
AI 리터러시는 AI 도구를 빠르게 사용하는 기술만을 의미하는 개념이 아님
AI가 무엇을 할 수 있고 어떤 한계를 가지는지 이해하며 결과를 검토하고 책임 있게 활용하는 능력
### 4.1 AI의 능력과 한계 이해
AI 리터러시의 출발점은 AI가 잘하는 일과 어려워하는 일을 구분하는 능력
- **잘하는 영역**: 대량 처리, 패턴 탐색, 분류, 예측, 추천, 초안 생성
- **한계 영역**: 맥락의 완전한 이해, 예외 판단, 책임, 사실성 자동 보장
- **예시**: AI가 자연스럽게 작성한 답변이라도 실제 사실과 다를 수 있는 상황
- **이해 포인트**: 결과의 품질과 결과의 신뢰성은 별도로 판단할 필요
---
### 4.2 AI 결과 검토
AI 결과를 그대로 받아들이지 않고 사실·맥락·출처·목적에 맞는지 확인하는 능력
- **사실 확인**: 날짜, 숫자, 인물, 사건 등 검증 가능한 정보 확인
- **출처 확인**: 인용과 참고자료가 실제 존재하는지 확인
- **맥락 확인**: 사용 목적과 대상에 맞는 답변인지 확인
- **누락 확인**: 중요한 조건이나 예외가 빠지지 않았는지 확인
- **예시**: AI가 제시한 논문 제목을 실제 학술 검색에서 다시 확인
- **이해 포인트**: AI의 답변은 최종본이 아니라 검토가 필요한 후보 결과로 보는 관점
---
### 4.3 책임 있는 AI 활용
AI를 사용할 때는 결과뿐 아니라 입력하는 정보와 결과를 사용하는 방식까지 함께 고려할 필요
- **입력 정보 관리**: 개인정보·회사 기밀·민감정보 입력 여부 확인
- **결과 사용 범위**: 초안인지 최종 의사결정 자료인지 구분
- **권리 확인**: 생성 콘텐츠의 저작권·초상권·출처 문제 확인
- **최종 책임**: AI가 만든 결과를 실제로 사용한 사람과 조직의 책임
- **예시**: AI가 작성한 보고서를 제출하기 전에 사실과 출처를 사람이 검토
- **이해 포인트**: AI 도구 사용 능력과 AI 리터러시는 동일한 개념이 아님
## 5. 디지털 리터러시와 AI 리터러시의 관계
AI 리터러시는 디지털 환경 전체를 다루는 디지털 리터러시 위에서 확장되는 역량으로 이해 가능
### 5.1 공통 기반
두 리터러시는 정보를 찾고 이해하고 판단하며 책임 있게 사용하는 능력을 공통 기반으로 가짐
- **공통 요소**: 정보 탐색, 이해, 검증, 생성, 소통, 책임
- **디지털 리터러시**: 디지털 환경 전반을 대상으로 하는 넓은 개념
- **AI 리터러시**: AI 시스템과 AI 결과를 이해하고 활용하는 데 초점을 둔 개념
- **예시**: 온라인 정보를 검증하는 능력은 디지털 리터러시이면서 AI가 생성한 답변을 확인할 때도 필요한 기반
- **이해 포인트**: AI 리터러시는 디지털 리터러시와 별개로 존재하기보다 그 위에서 확장되는 역량
---
### 5.2 차이점
디지털 리터러시와 AI 리터러시는 겹치는 부분이 많지만 초점을 두는 대상에서 차이
- **디지털 리터러시의 초점**: 검색, 플랫폼, 콘텐츠, 온라인 소통, 개인정보, 저작권 등 디지털 환경 전반
- **AI 리터러시의 초점**: AI의 작동 특성, 결과의 한계, 생성 결과 검토, 책임 있는 활용
- **예시**: 검색 결과의 출처를 확인하는 것은 디지털 리터러시, AI가 만든 답변의 사실성과 생성 특성을 이해하는 것은 AI 리터러시
- **이해 포인트**: 두 역량은 경쟁 관계가 아니라 상호 보완 관계
---
### 5.3 함께 필요한 이유
현재의 디지털 환경에서는 검색·추천·생성·자동화에 AI가 깊게 결합되어 있기 때문에 두 역량을 함께 사용하는 상황이 많음
- **검색**: 검색 결과와 AI 요약을 함께 판단
- **추천**: 알고리즘이 선택한 콘텐츠의 기준 이해
- **생성**: AI가 만든 콘텐츠의 사실성·출처·권리 검토
- **업무**: 자동화 결과와 사람의 최종 판단 구분
- **예시**: AI 검색 서비스가 제시한 답변을 읽고 원문 출처까지 확인하는 과정
- **이해 포인트**: AI 시대의 디지털 리터러시는 AI 결과를 이해하고 검토하는 능력까지 포함하는 방향으로 확장
## 6. AI와 디지털 리터러시의 현대적 역할
AI가 일상과 학습·업무에 널리 사용되면서 디지털 리터러시와 AI 리터러시는 단순한 선택 역량이 아니라 기본적인 판단 역량으로 중요성이 확대
### 6.1 학습과 정보 탐색
AI는 검색, 요약, 설명, 아이디어 생성 등을 통해 학습을 지원할 수 있지만 결과를 그대로 받아들이기보다 확인하는 과정이 필요
- **AI 활용**: 개념 설명, 자료 요약, 질문 생성, 학습 계획 초안
- **사람 역할**: 출처 확인, 내용 비교, 핵심 개념 이해, 최종 정리
- **예시**: AI가 요약한 논문 내용을 원문 초록과 비교
- **이해 포인트**: 학습 과정에서 AI는 사고를 대신하는 도구보다 사고를 지원하는 도구로 활용
---
### 6.2 콘텐츠 제작
AI는 글·이미지·음성·영상 제작의 진입 장벽을 낮추고 초안 제작 속도를 높이는 역할
- **AI 활용**: 문장 초안, 이미지 시안, 영상 구성안, 발표 자료 아이디어
- **사람 역할**: 목적 설정, 대상 조정, 사실 확인, 스타일 결정, 최종 편집
- **예시**: AI가 만든 카드뉴스 문구를 대상 연령에 맞게 사람이 수정
- **이해 포인트**: 생성 속도보다 결과의 목적 적합성과 책임 있는 사용이 중요
---
### 6.3 의사결정과 업무 지원
AI는 많은 자료를 분석하고 후보를 제시해 업무와 의사결정을 지원할 수 있지만 최종 판단의 기준과 책임은 별도
- **AI 활용**: 위험 점수, 추천 후보, 문서 요약, 일정 초안, 데이터 분석
- **사람 역할**: 중요 기준 설정, 예외 확인, 조직 규칙 적용, 최종 승인
- **예시**: 채용 지원서 요약을 AI가 돕더라도 최종 채용 판단은 사람이 다양한 기준을 종합해 결정
- **이해 포인트**: AI의 편리함이 판단 책임의 이전을 의미하지 않음
---
### 6.4 일상생활에서의 선택과 책임
추천 서비스, 검색, 쇼핑, 금융, 내비게이션 등 일상 속 많은 서비스에 AI가 이미 포함
- **추천**: 무엇을 볼지 선택하는 데 영향
- **검색**: 어떤 정보가 먼저 보일지 영향
- **쇼핑**: 상품 추천과 가격·수요 예측에 활용
- **금융**: 이상거래 탐지와 위험 분석에 활용
- **이동**: 경로·도착시간 예측에 활용
- **예시**: 추천 영상이 계속 비슷한 주제를 보여줄 때 다른 정보도 의도적으로 찾아보는 행동
- **이해 포인트**: AI 시대의 핵심 역량은 결과를 받는 것보다 **선택 → 확인 → 판단 → 책임**의 과정을 유지하는 것
<callout color="blue_bg">
	## 📌 학습 요약
	- AI는 주어진 목적에 따라 데이터를 처리하고 패턴을 이용해 결과를 만드는 시스템
	- 현재 사용하는 대부분의 AI는 특정 과제에 특화된 좁은 인공지능
	- AI의 대표 기능은 인식·분류·예측·추천·생성·의사결정 지원
	- AI 결과는 입력 → 처리 → 결과의 흐름으로 이해 가능
	- 데이터는 학습 재료, 알고리즘은 학습 방법, 모델은 학습 결과 형성된 계산 구조
	- AI는 대량 처리와 패턴 탐색에 강점, 사람은 목적 설정·맥락 판단·검토·책임에서 핵심 역할
	- 디지털 리터러시는 정보를 찾고 이해하고 판단하고 만들고 책임 있게 사용하는 종합 역량
	- AI 리터러시는 AI의 능력과 한계를 이해하고 결과를 검토하며 책임 있게 활용하는 역량
	- AI 시대의 핵심 태도는 **선택 → 확인 → 판단 → 책임**
