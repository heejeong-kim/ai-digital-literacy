[참고] 교재 속 용어
  1. 프롬프트 엔지니어링 (Prompt Engineering): 생성형 AI에서 원하는 결과를 얻기 위해 프롬프트를 설계하고 실행 결과를 확인하며 반복적으로 개선하는 과정. 프롬프트 설계 및 최적화라고도 함
  2. 생성형 AI (Generative AI): 텍스트, 이미지, 오디오, 동영상, 코드 등 새로운 콘텐츠를 생성하는 인공지능 기술 또는 모델
  3. 퓨샷 러닝 (Few-shot Learning): 제한된 수의 예시만으로 새로운 작업이나 개념의 패턴을 파악해 수행하는 능력 또는 학습 방식. 대화형 AI에서는 프롬프트에 예시를 제공하는 인컨텍스트 러닝(In-context Learning)의 의미로 주로 사용됨
  4. 퓨샷 프롬프팅 (Few-shot Prompting): 원하는 결과에 대한 두 개 이상의 예시를 프롬프트에 포함해 AI가 출력의 내용, 구조, 형식 또는 분류 기준을 파악하도록 유도하는 방법
  5. 제로샷 프롬프팅 (Zero-shot Prompting): 예시를 제공하지 않고 원하는 작업과 조건을 직접 요청하는 프롬프팅 방법
  6. 원샷 프롬프팅 (One-shot Prompting): 원하는 결과에 대한 예시를 하나 포함해 AI가 그 패턴을 참고하도록 하는 프롬프팅 방법
  7. 투샷 프롬프팅 (Two-shot Prompting): 원하는 결과에 대한 예시를 두 개 포함해 AI가 공통 패턴과 차이를 파악하도록 하는 프롬프팅 방법
  8. 목적 (Objective): 프롬프트를 통해 얻고자 하는 최종 목표 또는 산출물
  9. 맥락 (Context): AI가 요청을 이해하고 수행하는 데 필요한 배경 정보, 상황, 자료, 전제 조건
  10. 역할 또는 페르소나 (Role / Persona): AI가 특정 관점, 전문성 또는 업무 역할을 기준으로 답변하도록 지정하는 요소
  11. 청중 (Audience): AI가 생성한 결과물을 읽거나 활용할 대상. 청중에 따라 설명 수준, 전문 용어, 어조와 예시를 조정할 수 있음
  12. 예시 (Examples): AI가 원하는 답변의 내용, 구조, 형식 또는 스타일을 이해할 수 있도록 제공하는 구체적인 사례
  13. 형식 (Format): 결과물의 구조 또는 표현 형태. 예: 표, 목록, 문단, 보고서, 이메일
  14. 키워드 (Keywords): 결과물에 반드시 포함되어야 하는 핵심 단어나 개념
  15. 제약 조건 (Limitations / Constraints): 답변의 길이, 분량, 포함·제외할 내용, 대상 수준, 출력 형식 등에 대한 제한 조건
  16. 어조 (Tone): 결과물의 전반적인 분위기와 표현 방식. 예: 친절한, 전문적인, 간결한, 설득적인
  17. 제외 조건 (Negation / Negative Constraints): 결과물에서 포함하지 않아야 하는 내용, 표현 또는 행동을 지정하는 조건

1. 사용 환경과 기능 이해

1.1 도구별 기본 설정

생성형 AI를 사용하기 전에 계정과 화면, 개인화, 데이터, 권한 관련 기본 설정을 확인하여 기본 설정을 미리 점검하면 서비스별 기능 차이를 줄이고 자신의 목적에 맞는 작업 환경을 구성할 수 있음

설정 항목공통 확인 내용플랫폼별 특이사항
☑️ 계정·요금제로그인 계정, 무료·유료 여부, 조직·교육 계정, 사용 가능한 기능과 사용량 확인조직·교육 계정은 관리자 정책과 라이선스에 따라 기능 범위가 달라질 수 있음
화면·언어화면 언어, 시간대, 모바일·웹·데스크톱 환경, 메뉴 표시 상태 확인웹·모바일·데스크톱에 따라 메뉴 위치와 제공 기능이 다를 수 있음
모델·응답 설정사용 목적에 맞는 모델, 응답 길이, 응답 스타일, 작업 모드 선택모델 선택 메뉴와 응답 설정의 위치·이름이 서비스마다 다름
☑️ 개인화·맞춤 지침사용자의 역할·관심사·답변 선호도·자주 사용하는 형식 설정맞춤 지침, 프로젝트 지침, Gem, GPT 등 기능 이름과 설정 범위가 다름
☑️ 대화·기억 관리대화 저장 여부, 기억 사용 여부, 대화 삭제·보관·검색 방법 확인기억 기능과 임시 대화 기능의 제공 여부와 이름이 다를 수 있음
데이터 사용·개인정보대화와 업로드 파일의 저장·학습 활용 여부, 민감정보 입력 기준 확인개인 계정과 조직·교육 계정의 데이터 보호 정책이 다를 수 있음
파일·자료 기본 설정파일 업로드 방식, 지원 형식, 프로젝트 자료와 지식 파일 관리 방법 확인프로젝트·지식 파일·Drive 연계 등 자료 관리 방식이 서비스마다 다름
알림·공유알림 수신, 대화 공유, 결과물 공유, 링크 공개 범위 확인대화·문서·결과물별 공유 권한과 공개 범위가 다를 수 있음
연결 앱·권한외부 서비스 연결 여부, 읽기·쓰기·실행 권한, 연결 해제 방법 확인커넥터·연결 앱·Workspace 연계 기능의 제공 여부와 권한 범위가 다름

1.2 도구별 기본 설정

생성형 AI를 처음 사용할 때는 다음 세 가지 설정부터 확인함. 이 설정은 답변의 개인화 수준과 대화의 지속성, 이용 가능한 기능 범위에 영향을 줌

🔔 대표 도구 설정해 보기

  1. 계정과 요금제 확인
    • 개인 계정인지 조직·교육 계정인지 확인함
    • 무료·유료 요금제에 따라 사용할 수 있는 모델과 기능 범위를 확인함
    • 파일 업로드, 검색·심층 조사, 프로젝트, 맞춤 기능, 외부 연결 기능의 이용 가능 여부를 확인함
    • 수업이나 업무에서 사용할 계정과 개인적인 실험용 계정을 구분함
    • 계정에 따라 사용량과 기능 제공 범위가 달라질 수 있으므로 실제 화면을 기준으로 확인함
  2. 개인화·맞춤 지침 설정
    • 예) Claude > 설정 > 일반
    • 예) GPT > 설정 > 개인 맞춤 설정
    • 사용자의 역할·관심 분야·전문 수준을 입력함
    • 답변의 언어·어조·분량·구성 방식 등 선호하는 응답 형식을 설정함
    • 자주 수행하는 작업과 결과물의 형식을 알려 답변의 일관성을 높임
    • 예: "대학 강의용 자료를 준비하는 교수이며, 답변은 한국어로 작성하고 표와 사례를 포함해 설명함"
    • 개인화 설정은 모든 대화에 영향을 줄 수 있으므로 민감한 개인정보나 불필요한 정보를 입력하지 않음
  3. 대화 기록과 기억 관리 설정
    • 예) Claude > 설정 > 개인정보 보호
    • 예) GPT > 설정 > 데이터 제어
    • 이전 대화가 저장되는지와 대화 기록을 검색·삭제·보관하는 방법을 확인함
    • AI가 이전 대화의 일부 정보를 기억하고 다음 대화에 활용하는지 확인함
    • 개인적인 질문이나 임시 작업에는 기록과 기억을 남기지 않는 기능을 검토함
    • 장기 프로젝트에는 대화 기록과 기억 기능을 활용해 작업 맥락을 유지함
    • 기록·기억·데이터 사용 설정은 계정 유형과 서비스 정책에 따라 달라질 수 있으므로 개인정보와 기밀자료 입력 기준을 함께 확인함

4. 생성형 AI 기능 활용

생성형 AI의 공통 기능을 대화와 자료 처리에서 외부 도구 연결과 에이전트형 업무 수행까지 단계적으로 활용함

기능 제공 여부와 메뉴 이름은 계정·요금제·지역·업데이트·기기·관리자 설정에 따라 달라질 수 있으므로 수업 당일 화면을 기준으로 확인함

파일 첨부·분석(File Upload / Analysis)

문서·표·이미지·영상 등 사용자가 보유한 자료를 대화에 첨부하고 자료의 내용을 요약·분류·비교·추출·분석하며 자료에 근거한 질문으로 필요한 정보와 패턴을 찾고 원문과 분석 결과를 함께 확인하는 파일 첨부·분석(File Upload / Analysis)을 활용함

  • 우리 프로젝트 활용 예시: 프로젝트 자료를 첨부해 요약·분류·핵심 이슈 도출
  • 학생 활용 예시: 강의 PDF를 첨부해 주차별 핵심 개념·필수 용어·복습 문제를 표로 정리함
  • 업무 활용 예시: 매출 스프레드시트를 첨부해 전월 대비 변동·이상 수치·추가 확인이 필요한 항목을 분석함

웹 검색(Web Search)

현재 시점의 정보나 외부 자료가 필요한 경우 검색어와 조건을 지정해 웹에서 관련 정보를 찾고 검색 결과의 작성 기관·발행일·원문 링크를 확인해 필요한 내용만 결과물에 반영하는 웹 검색(Web Search)을 활용함

Claude, ChatGPT, Gemini: 웹 검색 기능이 활성화된 상태에서 진행함

  • 우리 프로젝트 활용 예시: 프로젝트 관련 최신 사례와 경쟁 서비스 조사
  • 학생 활용 예시: 전공 키워드와 기간을 지정해 최신 논문·기사·기관 자료를 검색하고 참고 링크를 정리함
  • 업무 활용 예시: 경쟁사와 산업 키워드를 지정해 최근 제품 출시·가격·고객 반응을 검색하고 비교함

심층 조사(Deep Research)

하나의 검색 결과에 의존하지 않고 여러 출처의 자료를 수집·비교·분석하며 조사 질문을 세분화하고 근거와 출처를 함께 제시해 보고서나 의사결정 자료로 정리하는 심층 조사(Deep Research)를 활용함

Claude, ChatGPT, Gemini: 심층 조사 기능을 선택하고 조사 질문·범위·출력 형식을 입력한 뒤 조사 계획과 출처를 확인함

  • 우리 프로젝트 활용 예시: 프로젝트의 시장·기술·사용자 자료를 조사하고 출처 정리
  • 학생 활용 예시: 연구 주제와 조사 질문을 입력해 논문·보고서의 연구 목적·방법·결과·한계를 비교표로 정리함
  • 업무 활용 예시: 신사업 주제에 대해 시장 규모·고객 문제·경쟁 현황·규제 이슈를 조사해 의사결정용 브리핑을 작성함

프로젝트(Projects)

특정 과제나 주제와 관련된 대화·파일·지침·결과물을 하나의 작업 공간에 모아 관리하고 이전 대화와 자료를 바탕으로 후속 작업을 이어가며 장기 과제의 맥락과 진행 상태를 유지하는 프로젝트(Projects)를 활용함

Claude, ChatGPT, Gemini: 프로젝트·맞춤 작업 공간을 만들고 관련 자료와 지침을 등록한 뒤 해당 공간에서 대화를 진행함

  • 우리 프로젝트 활용 예시: 프로젝트 대화·자료·결과물을 하나의 작업 공간에서 관리
  • 학생 활용 예시: 팀 과제의 강의자료·회의록·역할 분담표·발표 초안을 하나의 프로젝트 공간에서 관리함
  • 업무 활용 예시: 제품별 요구사항·회의 기록·고객 피드백·일정 자료를 프로젝트별로 축적함

자료 관리(Knowledge Management)

작업 과정에서 생성되거나 수집된 기획서·회의록·참고자료·피드백을 체계적으로 저장·분류하고 축적된 자료를 새로운 질문과 결과물 작성에 다시 활용해 같은 설명과 자료 준비를 반복하는 일을 줄이는 자료 관리(Knowledge Management)를 활용함

Claude, ChatGPT, Gemini: 프로젝트 지식·파일·연결 자료에 자료를 추가하고 자료의 범위와 활용 목적을 지정해 후속 작업에 사용함

  • 우리 프로젝트 활용 예시: 기획서·회의록·참고자료를 누적하고 다음 작업에 재사용
  • 학생 활용 예시: 과목별 강의자료와 과제 피드백을 저장하고 시험 전에 핵심 개념과 오답 내용을 다시 검색함
  • 업무 활용 예시: 제안서·계약서·회의록·업무 매뉴얼을 분류해 담당자가 필요한 자료를 빠르게 찾도록 관리함

외부 도구·서비스 연결(Connectors / Integrations)

생성형 AI에 외부 도구와 서비스(클라우드 저장소·메일·문서·업무 관리 도구 등)를 연결해 AI가 접근할 수 있는 자료와 수행할 수 있는 작업의 범위를 확인하고, 여러 서비스에 흩어진 자료를 검색·요약하거나 연결된 서비스의 후속 작업으로 이어가는 외부 도구·서비스 연결(Connectors / Integrations)을 활용함

Claude, ChatGPT, Gemini: 설정 또는 연결 앱에서 Notion·Google Drive·메일 등 사용할 도구를 선택하고 권한을 승인한 뒤 검색 범위와 접근 권한을 확인하고 연결된 자료와 기능을 대화에서 호출함

  • 우리 프로젝트 활용 예시: Drive·Notion·메일 등 프로젝트 서비스와 작업 도구를 연결해 자료 조회와 후속 작업 수행
  • 학생 활용 예시: 일정표·과제 목록이나 클라우드에 저장한 팀 회의록을 연결해 마감 과제·우선순위별 학습 계획이나 결정 사항을 정리함
  • 업무 활용 예시: 프로젝트 관리 도구의 미완료 업무나 메일·클라우드 문서의 고객 요청 사항을 조회해 지연 항목·이슈·우선순위·다음 조치를 정리함
  • 확인 사항: 연결 대상·접근 권한·데이터 공유 범위·실행 가능 작업 확인

에이전트 활용(Agents / Agentic Work)

AI에게 목표 달성에 필요한 여러 단계의 작업을 위임하는 에이전트 활용(Agents / Agentic Work)을 활용함. 위임 범위에 따라 크게 두 단계로 구분함

  • 대화 내 작업 위임(Agents): 조사·분석·작성·실행처럼 대화 안에서 처리 가능한 작업을 여러 단계로 나누어 위임하고, 작업 범위와 승인 지점을 정해 중간 결과와 최종 결과를 사용자가 확인함
  • 컴퓨터 제어형 작업 위임(Agentic Work): AI가 컴퓨터 환경에서 파일을 찾고 정리하거나 응용 프로그램을 직접 사용해 업무를 수행함. 실제 컴퓨터 조작에 앞서 실행 승인·제어 범위·개인정보·작업 결과를 확인함. Claude의 Cowork, ChatGPT의 Work·Agent, Gemini의 Spark가 이에 해당함

Claude, ChatGPT, Gemini: 에이전트 또는 에이전트형 업무 수행 기능을 선택하고 목표·작업 범위·완료 조건(또는 파일·앱 실행 권한)을 입력한 뒤 실행 과정과 결과를 검토함

  • 우리 프로젝트 활용 예시: 조사→분석→초안 작성 등 작업 흐름 위임, 또는 프로젝트 자료 정리·후속 업무 수행을 에이전트형 기능에 위임함
  • 학생 활용 예시: 참고 자료 수집→요약→발표 개요 작성을 에이전트 작업으로 구성하거나, 다운로드한 강의자료를 과목별 폴더로 정리하고 파일명을 규칙에 맞게 변경하도록 요청함
  • 업무 활용 예시: 경쟁사 조사→자료 비교→브리핑 작성까지 위임하되 최종 제출 전 결과를 검토하거나, 지정 폴더의 자료 분류·반복 정리 작업을 위임하되 실행 전 권한과 결과를 확인함
  • 확인 사항: 작업 범위·사용자 승인·컴퓨터 제어 범위·개인정보 보호·실행 결과·중단 방법 확인

스킬(Skills)

Skills를 통해 특정 업무의 절차·판단 기준·출력 형식·검토 방법을 정의하고 반복 작업에 적용해 담당자나 상황이 달라져도 일정한 품질과 형식의 결과를 만드는 스킬(Skills)을 활용함

Claude, ChatGPT, Gemini: 스킬·맞춤형 GPT·Gems 등에 작업 절차·판단 기준·출력 형식을 설정한 뒤 반복 업무에 적용함

  • 우리 프로젝트 활용 예시: 문서 형식·분석 기준·검토 절차를 스킬로 표준화
  • 학생 활용 예시: 자신의 수준에 맞춰 개념 설명·퀴즈 출제·오답 피드백을 제공하는 학습 스킬을 적용함
  • 업무 활용 예시: 회사 보고서의 문체·목차·표현 규칙을 스킬로 정의해 반복 문서에 일관되게 적용함
