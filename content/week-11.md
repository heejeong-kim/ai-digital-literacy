# 1. 생성형 AI 콘텐츠의 이해
## 1.1 콘텐츠는 결과물이 아니라 전달 과정
콘텐츠는 글·이미지·영상 자체만을 의미하지 않고 특정 대상에게 정보를 전달해 이해·판단·행동의 변화를 만드는 과정
> <span color="gray">예시) AI 보안 카드뉴스 만들기보다 대학생이 피싱 메시지를 받았을 때 세 가지 위험 신호를 확인하고 공식 경로에서 재확인하도록 돕는 카드뉴스처럼 목적과 행동을 먼저 정의하면 무엇을 넣고 뺄지 판단하기 쉬움</span>
---
## 1.2 생성형 AI가 바꾼 콘텐츠 제작 흐름
생성형 AI를 사용하면 글·이미지·영상의 초안을 만드는 시간과 비용이 크게 줄어듦. 대신 **무엇을 만들지 정하는 일**과 **만든 결과가 맞는지 확인하는 일**의 비중이 커짐

만드는 비용이 낮아질수록 기획 없이 일단 만들어 보는 일이 쉬워지므로, 오히려 기획의 중요성이 커짐
---
## 1.3 기획 없이 생성하면 생기는 문제
<callout color="blue_bg">
	### 실사례 : **AI 이미지로 홍보한 체험 행사**
	2024년 2월 영국 글래스고의 한 업체는 AI로 만든 화려한 초콜릿 공장 이미지로 어린이 체험 행사를 홍보하고 1인당 35파운드에 표를 판매함. 실제 행사장은 소품 몇 개만 놓인 창고였고, 홍보 이미지에는 AI 생성물에서 흔히 보이는 엉터리 글자가 들어 있었으며, 배우들이 받은 대본도 알아들을 수 없는 문장이 많았음. 항의가 이어져 경찰이 출동했고 업체는 전액 환불을 약속함, 출처: [NBC News(2024)](https://www.nbcnews.com/tech/willy-wonka-inspired-chocolate-experience-outrage-rcna140726)
	> 실제로 제공할 수 있는 내용과 맞지 않는 AI 콘텐츠는 아무리 그럴듯해도 신뢰를 잃게 만듦
</callout>
<callout color="blue_bg">
	### 실사례 : **AI로 다시 만든 크리스마스 광고**
	코카콜라는 2024년 11월 1995년의 대표 크리스마스 광고를 생성형 AI로 다시 만들어 공개했으나, 시청자들은 감동이 사라지고 기계적으로 느껴진다는 반응을 보이며 강하게 비판함. 코카콜라는 브랜드의 전통과 미래 기술을 연결한 시도라고 설명함, 출처: [Business Today(2024)](https://businesstoday.in/technology/news/story/death-of-art-coca-cola-faces-backlash-over-ai-generated-christmas-ad-453994-2024-11-16)
	> 기술적으로 만들 수 있다는 것과 대상이 기대하는 경험을 전달한다는 것은 다른 문제이므로, 대상과 메시지를 먼저 정해야 함
</callout>
두 사례 모두 생성 기술이 부족해서가 아니라 **대상이 무엇을 기대하는지, 실제와 표현이 일치하는지**를 기획 단계에서 충분히 확인하지 않아 문제가 커진 경우
---
## 1.4 AI 생성 콘텐츠의 표시와 신뢰
9주차에서 살펴본 것처럼 AI 기본법은 생성형 AI 결과물에 AI로 생성되었다는 사실을 표시하도록 정하고 있음. 콘텐츠 기획 단계에서는 표시 여부를 제작 마지막에 고민하기보다 처음부터 다음을 함께 정하는 것이 적절
- 어떤 부분을 AI로 만들 것인가
- 실제 사진·사건으로 오해될 수 있는 장면이 있는가
- AI 생성 사실을 어디에 어떻게 표시할 것인가
- 실제 사람의 얼굴·목소리·작품을 참고하는 부분이 있는가(7주차)
> <span color="gray">예시) 학교 행사 홍보물에 실제 행사장처럼 보이는 AI 이미지를 쓴다면 이미지 하단에 AI 생성 이미지라고 밝히거나, 실제 장소 사진과 AI 일러스트를 구분해 사용함</span>
---
# 2. 콘텐츠 기획의 기본 요소
5주차에서 다룬 프롬프트의 목적·대상·조건이 **AI에게 한 번 요청할 때의 기준**이라면, 11주차의 목적·대상·메시지는 **콘텐츠 전체를 만드는 동안 유지할 기준**이라는 점이 다름
---
## 2.1 목적(Objective)
목적은 콘텐츠를 본 사람이 무엇을 이해하거나 어떤 행동을 하기를 기대하는지 정하는 기준
- 개념 이해
- 서비스나 정책 안내
- 행동 유도
- 복잡한 자료의 빠른 비교
- 특정 문제에 대한 관심 유도
좋은 목적은 AI에 대해 소개한다처럼 넓은 표현보다 결과를 확인할 수 있는 형태로 구체화
- 약한 목적: 개인정보에 대한 콘텐츠를 만든다
- 개선된 목적: 대학생이 외부 AI 서비스에 문서를 입력하기 전에 개인정보 포함 여부를 확인하도록 5단계 체크리스트를 제공한다
---

## 2.4 핵심 메시지(Key Message)
핵심 메시지는 콘텐츠를 본 사람이 마지막까지 기억해야 할 중심 생각으로, 한 문장으로 설명할 수 있고 목적과 직접 연결되어야 함
- AI는 중요하다보다 AI 결과는 생성 속도보다 검증 과정이 중요하다
- 보안을 잘 지켜야 한다보다 의심 링크는 메시지 안에서 확인하지 말고 공식 앱이나 사이트에서 다시 확인한다
주제는 다룰 영역이고 핵심 메시지는 기억해야 할 결론이라는 점에서 다름
> <span color="gray">예시) 주제: 피싱 예방 / 핵심 메시지: 의심스러운 링크는 메시지에서 바로 열지 말고 공식 앱이나 주소에서 다시 확인한다</span>
세부 정보는 핵심 메시지를 설명하거나 근거를 제공하는 역할을 하도록 배치

## 2.6 범위 정하기
콘텐츠에 가능한 모든 정보를 넣는 것이 아니라 목적을 달성하는 데 필요한 범위를 설정
- **반드시 포함**: 핵심 메시지를 이해하는 데 꼭 필요한 개념과 근거
- **있으면 좋은 내용**: 이해를 돕지만 없어도 핵심 메시지가 유지되는 사례나 배경
- **제외**: 주제와 관련은 있지만 현재 대상과 목적에는 필요하지 않은 내용
AI는 많은 내용을 빠르게 만들어 내므로 범위를 정하지 않으면 콘텐츠가 오히려 산만해질 수 있음. 분량을 줄이는 것은 대충 만드는 것이 아니라 대상과 목적에 맞게 우선순위를 정하는 작업
---

## 3.2 정보 구조(Content Structure)
정보 구조는 내용을 어떤 순서로 보여줄지 정하는 방식
**설명형 흐름**
1. 현재 상황 또는 문제
2. 왜 중요한가
3. 핵심 개념
4. 근거 또는 이유
5. 실제 사례
6. 해결 방법 또는 적용 방법
7. 행동 요청 또는 핵심 정리
모든 콘텐츠가 같은 구조를 사용할 필요는 없으며, 대상이 이미 문제를 알고 있다면 배경 설명을 줄이고 해결 방법을 앞쪽에 배치할 수 있음

## 3.4 톤과 표현 기준
톤은 콘텐츠 전체에서 유지할 말투와 분위기
- 전문적이고 설명적인 톤
- 친근하고 간결한 톤
- 경고와 행동을 강조하는 톤
- 기관의 공식적인 안내 톤
AI에게 매번 자연스럽게 써줘라고 요청하기보다 문장 길이·용어 수준·존댓말 여부·금지 표현 등을 구체적으로 정하면 여러 결과의 일관성을 높일 수 있음
---
## 3.5 검수 기준을 먼저 정하기
완성 후 괜찮아 보이는지 판단하기보다 제작 전에 기준을 정하면 수정이 쉬워짐
- 핵심 메시지가 한 문장으로 설명되는가
- 대상에게 어려운 용어가 과도하지 않은가
- 중요한 주장에 확인 가능한 근거가 있는가(3·10주차)
- 장면·슬라이드마다 역할이 분명하고 같은 내용이 반복되지 않는가
- 이미지·음성·음악의 사용 권리와 개인정보를 확인했는가(7주차)
- 특정 집단을 고정관념으로 표현하지 않았는가(9·10주차)
- AI 생성 부분을 표시하고 실제와 혼동되지 않게 했는가(1.4)
- 마지막에 사용자가 취할 행동이 분명한가

# 4. LLM을 활용한 기획 워크플로
## 4.1 LLM은 정답보다 대안을 넓히는 도구
대규모 언어 모델을 기획에 활용할 때 가장 유용한 방식은 여러 선택지를 빠르게 만들어 비교하는 것
**발산**: 가능한 선택지를 넓게 만듦
- 제목 후보 10개
- 대상이 궁금해할 질문 10개
- 사례 후보 5개
- 서로 다른 구조 3개
**수렴**: 정해 둔 기준으로 사람이 후보를 줄임
- 목적과 맞는가
- 대상이 이해할 수 있는가
- 근거를 확보할 수 있는가
- 제작 시간 안에 가능한가
- 불필요하게 과장되지 않았는가
첫 번째 AI 제안을 바로 채택하면 다양한 대안을 탐색하는 생성형 AI의 장점을 충분히 활용하지 못함
---
## 4.2 브리프를 기준으로 단계별로 요청하기
AI에게 완성본부터 요청하면 목적·구조·문장·이미지가 한꺼번에 정해져 어디가 문제인지 찾기 어려움. 브리프를 먼저 제공하고 **지금 단계에 필요한 결과만** 요청하면 기획과 제작을 분리해 관리할 수 있음

</callout>
브리프를 대화 처음에 넣어 두면 단계가 바뀌어도 같은 기준을 유지하기 쉬움. 다만 대화가 길어지면 앞의 조건이 약하게 반영될 수 있으므로(10주차 맥락 창) 단계가 바뀔 때마다 핵심 조건을 다시 확인

## 4.3 반대 관점과 누락 확인
LLM에게 자신의 기획을 칭찬하게 하기보다 실패 가능성과 누락을 의도적으로 질문할 수 있음
- 이 기획이 대상에게 어렵게 느껴질 수 있는 부분은?
- 핵심 메시지와 직접 연결되지 않는 내용은?
- 사용자가 오해할 수 있는 표현은?
- 반대 사례나 예외는?
- 실제 행동으로 이어지지 않을 이유는?
AI가 제시한 비판도 정답은 아니므로 사람이 실제 목적과 근거에 맞는지 다시 판단

**⑦ AI 활용 계획**
- 텍스트 AI: 제목·문장 후보 발산 → 사람이 선택·수정
- 이미지 AI: 카드 1·2의 일러스트 생성 → 마지막 카드에 AI 생성 이미지 표시
- 사례·수치는 AI에 맡기지 않고 원문으로 확인
**⑧ 검수 기준**
- 10주차의 생성 원리·환각 설명과 모순되지 않는가
- 사례의 날짜·금액이 원문과 같은가
- 한 카드에 메시지가 하나만 들어 있는가
- 일러스트의 인물 표현이 특정 성별·외모로 치우치지 않았는가
<callout icon="💡" color="blue_bg">
	생성형 AI 콘텐츠 기획의 핵심은 AI에게 무엇을 만들게 할지보다 먼저 사람이 **왜 만들고 누구에게 무엇을 전달할지**를 정하는 데 있음. 목적 → 대상 → 핵심 메시지 → 구조 → 장면 → 검수 기준이 분명할수록 AI 결과를 선택하고 수정하는 기준도 선명해짐
</callout>
