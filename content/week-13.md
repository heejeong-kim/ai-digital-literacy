## 2.2 짧은 프롬프트와 구조화 프롬프트 비교
같은 제품으로 두 가지 프롬프트를 입력하고 결과를 나란히 비교
**프롬프트 1 — 짧은 요청**
```plain text
수분 크림 광고 포스터 만들어줘
```
**프롬프트 2 — 구조화 요청**
```plain text
가상 브랜드 화장품의 광고 포스터용 제품 이미지를 만들어줘.
- 주제: 둥근 반투명 하늘색 유리 용기에 흰색 뚜껑이 있는 수분 크림 1개, 뚜껑 위에 작은 물방울 모양 로고
- 환경: 잔잔한 물 위에 놓인 흰색 원형 받침대, 주변에 작은 물방울
- 구도: 제품은 화면 아래쪽 중앙, 위쪽 40%는 제목을 넣을 수 있게 단순한 하늘색 배경으로 비워줘
- 시점: 제품보다 약간 낮은 시점, 제품 전체가 보이게
- 조명: 왼쪽 위에서 들어오는 부드러운 자연광, 유리에 자연스러운 반사
- 색조: 하늘색과 흰색 중심, 연한 민트색 포인트
- 스타일: 깨끗한 상업용 제품 사진
- 화면비: 3:4
- 이미지 안에는 글자를 넣지 마
```
**비교할 것**
- 제품이 가장 먼저 눈에 들어오는가
- 제목과 문구를 넣을 공간이 있는가
- 결과를 수정할 때 어느 요소를 바꾸면 되는지 알 수 있는가
짧은 요청은 AI가 제품 모양·배경·색을 임의로 정하므로 결과가 마음에 들지 않을 때 **무엇을 고쳐야 할지 찾기 어려움**. 구조화 프롬프트는 요소별로 하나씩 바꾸며 비교할 수 있음

## 2.4 포스터 문구는 디자인 도구에서 넣기
이미지 생성 AI가 글자를 그리는 능력은 좋아지고 있지만 브랜드명·용량·문구는 여전히 틀리거나 어색하게 생성될 수 있음. **정확해야 하는 글자는 디자인 도구에서 직접 입력**
- 이미지는 글자 없이 생성
