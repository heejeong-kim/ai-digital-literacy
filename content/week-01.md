# 1. AI의 정의와 기본 개념
## 1.1 인공지능(Artificial Intelligence)이란 무엇인가
인공지능은 사람이 하던 인식·분류·예측·추천·생성 같은 일을 컴퓨터가 수행할 수 있도록 만든 기술을 의미
현재 우리가 사용하는 AI는 사람처럼 스스로 목적을 정하고 판단하는 존재가 아니라, 사람이 정한 문제와 목적에 맞춰 데이터를 처리하고 학습된 패턴을 이용해 결과를 만드는 시스템
**AI의 핵심은 사람이 하던 일부 지적 활동을 컴퓨터가 처리**
- 사람이나 사물을 알아보는 인식
- 정보를 정해진 범주로 나누는 분류
- 앞으로 나타날 값이나 가능성을 추정하는 예측
- 사용자의 관심 가능성이 높은 항목을 제시하는 추천
- 새로운 글·이미지·음성·코드 등을 만드는 생성
**같은 AI라도 어떤 문제를 해결하도록 설계되었는지에 따라 다른 역할**
- 번역 AI는 언어를 다른 언어로 바꾸는 목적에 맞춰 동작
- 추천 AI는 사용자가 관심을 가질 가능성이 높은 콘텐츠를 찾는 목적에 맞춰 동작
- 이미지 생성 AI는 사용자의 요청을 바탕으로 새로운 이미지를 구성하는 목적에 맞춰 동작
따라서 AI를 이해할 때는 ‘사람처럼 생각하는가’보다 ‘어떤 목적을 위해 어떤 데이터를 처리하고 어떤 결과를 만드는가’를 살펴보는 것이 중요
---

**일상의 AI 사례**
이 사례들의 공통점은 AI가 사람 대신 모든 것을 결정하는 것이 아니라 특정 문제를 빠르게 처리하도록 설계된 것

### 1.1.2 AI는 무엇을 할 수 있는가
AI는 하나의 기능만 수행하는 기술이 아니라, 문제의 목적에 따라 서로 다른 기능을 사용하거나 여러 기능을 함께 조합하는 방식으로 활용
**① 인식(Recognition)**
인식은 사진·음성·문자·영상처럼 복잡한 입력 안에서 사람의 얼굴, 사물, 말소리, 글자처럼 의미 있는 대상을 찾아내는 기능으로 입력 안에서 필요한 특징을 찾아 “무엇이 있는지” 또는 “어디에 있는지”를 알아내는 단계
- 스마트폰 카메라가 사진 속 얼굴 위치를 찾아 자동으로 초점을 맞추는 기능
- 음성 비서가 사용자의 말을 분석해 문자로 변환하는 기능
- 문서 이미지에서 글자 영역을 찾아 텍스트로 변환하는 기능
> <span color="gray">예시) 스마트폰 카메라가 여러 사물이 함께 있는 화면에서 사람 얼굴의 위치를 먼저 찾아 초점을 맞춤</span>
인식은 그 자체로 끝나기도 하지만, 인식한 결과를 바탕으로 이후 분류·예측·추천 기능이 이어지는 경우도 있음
**② 분류(Classification)**
분류는 입력된 정보를 미리 정해 둔 범주 가운데 하나 또는 여러 범주로 나누는 기능으로 핵심은 AI가 새로운 범주를 자유롭게 만드는 것이 아니라, 사람이 정한 분류 기준 안에서 가장 적절한 범주를 선택하는 데 있음
- 이메일을 스팸과 정상 메일로 구분
- 제품 사진을 정상 제품과 불량 제품으로 구분
- 고객 문의를 배송·결제·환불·기타 유형으로 구분
> <span color="gray">예시) 이메일 서비스가 제목·본문·발신 패턴을 분석해 해당 메일이 스팸인지 정상 메일인지 판단</span>
분류에서는 어떤 범주로 나뉘는지만 보는 것이 아니라, 정상 메일이 스팸으로 분류되는 것처럼 잘못된 분류가 발생할 가능성도 함께 이해할 필요가 있음
**③ 예측(Prediction)**
예측은 과거와 현재의 데이터를 바탕으로 앞으로 나타날 값이나 사건의 가능성을 추정하는 기능으로 AI가 미래를 정확히 아는 것이 아니라, 이전 데이터에서 반복적으로 나타난 패턴을 이용해 “앞으로 어떻게 될 가능성이 높은가”를 계산하는 방식
- 내비게이션의 예상 도착 시간 계산
- 쇼핑몰의 다음 달 판매량 예상
- 기계의 고장 가능성 추정
- 고객의 서비스 이탈 가능성 예측
> <span color="gray">예시) 내비게이션이 현재 위치, 이동 속도, 도로 상황, 과거 교통 데이터를 함께 분석해 예상 도착 시간을 제시</span>
예측 결과는 확정된 미래가 아니라 현재 데이터와 과거 패턴을 바탕으로 계산한 가능성이므로 실제 상황이 바뀌면 결과도 달라질 수 있음
**④ 추천(Recommendation)**
추천은 많은 선택지 가운데 사용자가 관심을 가질 가능성이 높은 항목을 우선적으로 제시하는 것으로 사용자의 시청 기록·검색 기록·클릭·구매 내역과 비슷한 사용자의 행동 등을 분석해 개인별로 다른 결과를 구성하는 경우가 많음
- 동영상 플랫폼의 추천 영상
- 음악 서비스의 추천 곡
- 쇼핑몰의 추천 상품
- 온라인 강의 플랫폼의 추천 콘텐츠
> <span color="gray">예시) 같은 동영상 플랫폼을 사용해도 사람마다 이전 행동과 관심 패턴이 다르기 때문에 첫 화면에 서로 다른 영상이 보임</span>
추천 결과는 전체 콘텐츠의 객관적인 순위가 아니라 서비스가 정한 목표와 사용자 데이터에 따라 달라지는 개인화된 결과
**⑤ 생성(Generation)**
생성은 학습한 패턴을 바탕으로 기존 정보를 분류하거나 찾는 데서 그치지 않고 새로운 텍스트·이미지·음성·영상·코드 등을 구성하는 것으로 사용자가 질문이나 지시를 입력하면 AI는 학습된 패턴을 이용해 그 요청에 맞는 새로운 형태의 결과를 만들어 냄
- 질문에 대한 답변이나 글의 초안 작성
- 설명 문장을 바탕으로 새로운 이미지 생성
- 음성 합성이나 음악 생성
- 프로그램 코드나 문서 초안 생성
> <span color="gray">예시) “대학생 대상 AI 입문 강의를 소개하는 문장을 작성해줘”라고 입력하면 생성형 AI가 새로운 소개문을 구성</span>
생성 결과는 자연스럽고 완성도 높게 보일 수 있지만, 사실성·정확성·출처까지 자동으로 보장되는 것은 아니므로 결과를 사용하는 사람의 확인과 판단이 필요

## 1.2 AI는 어떻게 결과를 만드는가
AI는 입력된 정보를 바탕으로 학습한 패턴과 계산 방법을 이용해 결과를 생성하며, 기본 흐름은 입력 → 처리 → 결과로 이해할 수 있음
- **입력**: AI가 처리할 정보가 들어오는 단계
- **처리**: 학습한 패턴과 계산 방법을 이용해 입력의 특징과 관계를 분석하는 단계
- **결과**: 분석한 내용을 바탕으로 분류·예측·추천·생성 등의 결과를 제공하는 단계

### 1.2.1 데이터(Data)·알고리즘(Algorithm)·모델(Model)
AI가 새로운 입력을 보고 결과를 만들 수 있는 이유는 많은 데이터를 이용해 패턴을 학습한 결과가 모델에 반영되어 있기 때문임. 데이터·알고리즘·모델은 각각 따로 외우기보다 하나의 흐름으로 이해하는 것이 중요
**AI가 만들어지는 기본 흐름**
- 학습에 필요한 데이터를 준비
- 알고리즘을 이용해 데이터에서 특징과 관계를 학습
- 학습한 결과가 모델에 반영
- 완성된 모델이 새로운 입력을 받아 결과를 제공
즉 데이터 → 학습 알고리즘 → 모델 → 새로운 입력 → 결과의 구조
비유해서 보면 학생이 새로운 유형의 문제를 풀 수 있게 되는 과정과 비슷함. 데이터는 여러 문제와 사례, 알고리즘은 틀린 부분을 확인하며 풀이 방식을 개선하는 학습 방법, 모델은 그 학습 결과가 반영되어 새로운 문제에 답할 수 있게 된 상태에 해당
---
**① 데이터(Data): AI가 배우는 재료**
데이터는 AI가 학습할 때 사용하는 사례와 정보이며, 목적에 따라 다양한 형태로 활용
- **정형 데이터(Structured Data)**: 행과 열처럼 일정한 구조로 정리된 데이터
	- 고객의 나이·구매금액·방문 횟수
	- 월별 판매량·가격·재고량
- **비정형 데이터(Unstructured Data)**: 일정한 표 구조로 정리하기 어려운 데이터
	- 문서·이메일·SNS 게시글
	- 사진·영상·음성
AI 학습에서는 데이터의 양뿐 아니라 품질과 대표성도 중요
- **양**: 다양한 상황을 학습할 만큼 충분한 사례
- **품질**: 오류·중복·잘못된 값이 적고 목적에 맞는 데이터
- **대표성**: 특정 집단이나 상황에 치우치지 않고 실제 사용 환경을 충분히 반영하는 정도
> <span color="gray">예시) 특정 연령대의 얼굴 사진만으로 얼굴 인식 AI를 학습하면 다른 연령대에서 정확도가 낮아질 수 있음</span>
---
**② 알고리즘(Algorithm): 데이터에서 패턴을 배우는 방법**
알고리즘은 데이터를 어떤 방식으로 분석하고 패턴을 학습할지를 정하는 계산 방법과 절차
- 데이터에서 특징과 관계를 계산
- 결과를 평가하고 필요한 경우 계산값을 조정
- 이 과정을 반복하며 문제 해결에 필요한 패턴을 학습
대표적인 학습 방식에서는 AI가 예측한 결과와 정답의 차이를 비교하고 오류가 줄어들도록 내부 계산값을 조정하기도 함. 구체적인 학습 방식은 2주차에서 더 자세히 다룸
---
**③ 모델(Model): 학습 결과가 반영된 실제 AI**
모델은 데이터와 알고리즘을 이용한 학습 결과가 반영된 계산 구조로, 새로운 입력을 받아 실제로 분류·예측·추천·생성 등의 결과를 만듦
- 이미지 분류 모델: 새로운 사진의 범주를 계산
- 수요 예측 모델: 새로운 조건에서 예상 판매량을 계산
- 추천 모델: 사용자의 행동을 바탕으로 관심 가능성이 높은 항목을 계산
- 생성형 AI 모델: 입력된 요청을 바탕으로 새로운 텍스트·이미지 등의 결과를 생성
우리가 AI 서비스를 사용할 때 직접 이용하는 것은 학습 과정 자체가 아니라 이미 학습된 모델
---
### 1.2.2 예시로 이해하는 ‘데이터 - 알고리즘 - 모델’
고양이와 강아지를 구분하는 AI를 만든다고 가정
① **데이터 준비**
- 고양이와 강아지 사진을 충분히 수집하여 각 사진에 어떤 동물인지 정답 정보를 함께 준비

③ **모델 완성**

## 1.3 AI와 사람은 같은 방식으로 판단하는가
AI가 자연스러운 문장을 만들고 질문에 답하며 복잡한 문제를 해결하는 모습을 보면 사람처럼 이해하고 판단하는 것처럼 느껴질 수 있으나 AI와 사람은 결과를 만드는 방식에 차이가 있음
---
### 1.3.1 AI의 판단은 어떻게 만들어지는가
AI는 학습한 데이터에서 발견한 패턴과 관계를 바탕으로, 새로운 입력에 대해 가장 가능성이 높은 결과를 계산
- 텍스트 생성 AI는 앞뒤 문맥을 바탕으로 다음에 올 가능성이 높은 표현을 선택
- 이미지 분류 AI는 학습한 이미지 특징과 새로운 이미지의 특징을 비교해 가장 가능성이 높은 범주를 선택
- 추천 AI는 사용자의 과거 행동과 비슷한 이용자의 패턴을 바탕으로 관심 가능성이 높은 항목을 제시
즉 AI의 판단은 경험·감정·가치관을 바탕으로 한 인간의 판단이라기보다, 학습된 데이터와 계산 구조를 이용한 확률적 추정에 가까움

### 1.3.2 AI가 잘 판단하는 영역과 사람이 확인해야 하는 영역

- 대량의 이미지에서 특정 사물을 찾기
- 거래 기록에서 이상 패턴 탐지
- 과거 데이터를 바탕으로 수요나 위험 가능성 예측
- 많은 콘텐츠 가운데 개인의 관심 가능성이 높은 항목 추천
**사람의 확인과 판단이 필요한 부분**
- 정보가 사실인지 확인해야 하는 경우
- 상황의 맥락과 예외를 고려해야 하는 경우
- 사람에게 미치는 영향이 큰 결정
- 공정성·윤리·책임과 관련된 문제
---
### 1.3.3 그럴듯한 결과가 곧 ‘이해’를 의미하지는 않음
AI는 학습한 데이터에서 발견한 패턴을 바탕으로 현재 입력에 적절하거나 가능성이 높은 결과를 계산하지만, 그 결과가 정확하거나 자연스러워 보여도 의미와 맥락을 사람처럼 이해하고 판단하는 것은 아님
- 이미지 인식 AI가 사진을 ‘고양이’로 정확히 분류하더라도 정확한 분류와 고양이에 대한 경험적 이해는 서로 다른 문제
- 추천 AI가 사용자가 좋아할 영상을 잘 추천해도 사용자의 실제 취향과 선택 이유까지 파악했다고 볼 수 없음
- 예측 AI가 높은 정확도로 수요를 예측해도 사회적 상황이나 갑작스러운 변화의 의미까지 스스로 해석하지는 못함
- 글을 만드는 AI가 자연스러운 설명을 제시하더라도 내용의 사실성·근거·출처는 별도로 확인해야 함
즉, AI의 결과를 평가할 때는 ‘사람처럼 보이는가’보다 결과가 어떤 데이터와 패턴을 바탕으로 만들어졌는지, 현재 상황에 적절한지, 추가 확인이 필요한지를 살펴봐야 함. AI의 결과를 사용할 때는 다음을 구분할 필요가 있음
- 문장이 자연스러운가
- 질문에 잘 맞는가
- 사실이 정확한가
- 근거와 출처를 확인할 수 있는가
- 현재 상황에 적용해도 되는가
---
### 1.3.4 사람의 역할은 최종 판단을 완성하는 것
AI가 빠르게 정보를 처리하고 초안을 만들수록 사람의 역할이 사라지는 것이 아니라, 오히려 결과를 해석하고 검토하는 역할이 중요해짐
- AI는 가능한 결과를 빠르게 제시
- 사람은 그 결과가 정확하고 적절한지 검토
- 필요하면 추가 자료를 확인하고 수정
- 최종적으로 어떤 결과를 사용할지 결정
<callout icon="💡" color="blue_bg">
	AI는 학습된 데이터와 패턴을 바탕으로 가능성이 높은 결과를 계산하고, 사람은 그 결과의 의미·맥락·정확성·책임까지 판단
</callout>

# 2. 디지털 리터러시란 무엇인가? (의미와 중요성)
## 2.1 디지털 리터러시(Digital Literacy)란 무엇인가
디지털 리터러시는 디지털 환경에서 정보를 찾고 이해하고 평가하며, 목적에 맞게 만들고 소통하고, 안전하고 책임 있게 활용하는 종합적인 역량으로 핵심은 ‘기기를 얼마나 잘 다루는가’보다 디지털 환경에서 정보를 어떻게 판단하고 적절하게 행동하는가에 있음

### 2.1.2 디지털 환경에서 리터러시의 범위가 넓어진 이유
전통적인 문해력이 글을 읽고 이해하며 자신의 생각을 표현하는 능력에 초점을 두었다면, 디지털 환경에서는 다루어야 할 정보의 형태와 활동 범위가 훨씬 넓어짐
- 텍스트뿐 아니라 검색 결과·영상·이미지·데이터·온라인 게시물처럼 다양한 형태의 정보를 해석
- 필요한 정보를 직접 찾고 여러 출처를 비교하여 사용할 정보를 선택
- 정보를 문서·이미지·영상 등으로 재구성해 다른 사람과 공유
- 온라인 서비스와 AI가 제공하는 결과를 그대로 받아들이지 않고 목적과 맥락에 맞게 판단
따라서 디지털 리터러시는 읽기와 쓰기를 대체하는 새로운 능력이라기보다, 기존의 문해력이 디지털 환경의 탐색·평가·생성·공유까지 확장된 형태로 이해할 수 있음
---
## 2.2 왜 디지털 리터러시가 중요한가
디지털 환경에서는 정보의 양과 접근 속도가 크게 증가했고 누구나 정보를 생산하고 공유할 수 있게 되면서 그만큼 사용자가 직접 정보의 가치와 신뢰성, 활용 방법, 공유에 따른 책임을 판단해야 하는 상황도 많아짐
### 2.2.1 정보가 많아도 좋은 판단이 자동으로 만들어지지는 않음
검색 한 번으로 수많은 자료를 얻을 수 있지만, 검색 결과의 상단 노출·조회 수·좋아요 수는 정보의 정확성을 보장하지 않음. 중요한 것은 정보의 양보다 어떤 정보를 선택하고 어떤 근거로 판단할 것인지에 대한 기준
- 같은 사건도 작성자와 매체에 따라 강조하는 내용이 다를 수 있음
- 오래된 정보가 현재에도 유효한 것처럼 다시 공유될 수 있음
- 광고나 홍보 콘텐츠가 일반 정보처럼 보일 수 있음
- 일부 사실만 제시하면 전체 맥락과 다른 인상을 만들 수 있음
> <span color="gray">예시) 하나의 보고서가 기사·카드뉴스·SNS 게시물처럼 짧은 형식으로 다시 전달되는 과정에서 조사 조건이나 예외 사항이 빠질 수 있음. 짧게 정리된 정보일수록 원래 내용의 맥락이 그대로 유지되었는지 생각할 필요가 있음</span>
---
### 2.2.2 디지털 환경에서는 소비자이면서 동시에 생산자
디지털 공간에서 사용자는 정보를 읽기만 하는 사람이 아니라 댓글·게시물·영상·문서·이미지 등을 직접 만들고 다른 사람에게 전달하는 생산자이기도 하므로 정보를 생산하고 공유할 때는 다음과 같은 판단이 함께 필요
- 이 내용이 사실에 근거하는가
- 다른 사람의 권리나 개인정보를 침해하지 않는가
- 공개 범위가 적절한가
- 잘못 전달될 가능성은 없는가
- 내가 이 정보를 공유한 결과에 책임질 수 있는가
---
### 2.2.3 알고리즘과 AI가 ‘보이는 정보’에도 영향을 줌
오늘날의 디지털 환경에서는 같은 서비스를 이용하더라도 사람마다 정보가 노출되는 순서와 범위가 달라질 수 있음. 검색 결과·추천 영상·쇼핑 상품·광고·SNS 피드 등은 서비스의 기준과 사용자의 행동 데이터를 바탕으로 정보의 순서와 노출 범위를 달리 구성하는 경우가 있음
**왜 사람마다 다른 정보가 보일까**
- 이전 검색·클릭·시청·구매·저장 기록
- 위치·시간·사용 기기와 같은 상황 정보
- 다른 이용자의 반응
- 서비스가 정한 최신성·인기·관련성 등의 기준
이러한 개인화는 필요한 정보에 빠르게 도달하도록 돕지만, 비슷한 정보가 반복적으로 보이거나 상단에 노출된 결과를 전체 정보 또는 가장 신뢰할 만한 정보로 오해하게 만들 수도 있음
예) 영상 플랫폼에서 한 사람에게는 여행 영상이, 다른 사람에게는 게임 영상이 많이 보일 수 있음. 같은 서비스를 사용해도 이전 행동과 관심 패턴이 다르기 때문에 추천 결과가 달라지는 것
따라서 디지털 리터러시에서는 화면에 보이는 정보 자체뿐 아니라 어떤 기준으로 선택되고 배열되었는지까지 함께 살펴보는 태도가 필요
- 왜 이 정보가 나에게 보이는가
- 이 결과는 전체 정보인가, 일부가 선택된 결과인가
- 다른 검색어나 출처에서는 무엇이 보이는가
- 많이 추천된 정보와 신뢰할 수 있는 정보는 같은 의미인가
디지털 환경에서 정보를 잘 이용한다는 것은 보이는 결과를 빠르게 선택하는 데 그치지 않고, 필요한 경우 정보의 범위와 관점을 스스로 넓혀 보는 것까지 포함
---
## 2.3 디지털 리터러시를 구성하는 주요 능력
디지털 리터러시는 하나의 기술이 아니라 탐색 → 이해와 평가 → 생성 → 소통 → 안전과 책임이 서로 연결된 역량
이 다섯 영역은 정해진 순서대로 한 번씩 수행하고 끝나는 단계라기보다, 디지털 활동의 목적과 상황에 따라 반복해서 연결되는 관계. 한 영역이 부족하면 다른 영역을 잘 수행하더라도 전체적인 판단의 질이 낮아질 수 있음
> <span color="gray">예시) 필요한 자료를 빠르게 찾는 탐색 능력이 뛰어나도 출처와 근거를 평가하는 능력이 부족하면 잘못된 정보를 그대로 사용할 수 있으며, 신뢰할 만한 정보를 찾았더라도 안전과 책임을 고려하지 않으면 개인정보나 타인의 권리를 침해하는 방식으로 공유할 수 있음</span>
**① 정보 탐색**
필요한 정보가 무엇인지 정하고, 목적에 맞는 검색어와 자료원을 선택해 필요한 정보를 찾는 능력
- 과제 주제에 맞는 공식 자료와 통계 찾기
- 최신 정보가 필요한지 원자료가 필요한지 구분하기
- 검색 결과 하나에 의존하지 않고 여러 자료를 비교하기
**② 정보 이해와 평가**
찾은 정보를 그대로 받아들이지 않고 출처·근거·작성 시점·맥락을 살펴 신뢰성과 적절성을 판단하는 능력
- 누가 만들었는지 확인
- 주장을 뒷받침하는 근거가 있는지 확인
- 오래된 정보인지 현재에도 유효한지 확인
- 다른 자료와 비교했을 때 내용이 일치하는지 확인
**③ 콘텐츠 생성**
디지털 도구를 이용해 정보를 단순히 복사하는 것이 아니라 목적과 대상에 맞게 재구성하고 표현하는 능력
- 문서·발표자료·이미지·영상 제작
- 자료의 핵심 내용을 요약하고 시각화
- 출처를 표시하고 다른 사람의 콘텐츠를 적절하게 활용
**④ 소통과 협업**
온라인 공간의 특성을 이해하고 다른 사람과 효과적이고 책임 있게 의견을 나누고 공동 작업을 수행하는 능력
- 공유 문서에서 역할과 버전 관리
- 메시지의 표현 방식과 전달 범위 고려
- 공개 공간과 사적 공간을 구분해 소통
**⑤ 안전과 책임**
디지털 활동에서 발생할 수 있는 개인정보·보안·권리·윤리 문제를 인식하고 자신의 행동에 책임을 지는 능력
- 개인정보와 계정 정보 보호
- 다른 사람의 저작물과 초상·개인정보 존중
- 확인되지 않은 정보를 무분별하게 공유하지 않기
---

## 3.1 학습에서는 ‘답을 얻는 것’보다 ‘이해하고 재구성하는 것’이 중요
AI를 활용하면 어려운 개념에 대한 설명을 요청하고, 긴 자료를 요약하며, 아이디어를 정리하거나 글의 초안을 빠르게 만들 수 있음. 이때 AI가 제공한 결과를 학습자가 실제로 이해하고 자신의 지식으로 연결하는 것이 훨씬 더 중요해짐
- AI가 설명한 개념을 자신의 말로 다시 설명할 수 있는지 확인
- 교재·강의자료·공식 자료와 비교해 사실과 근거를 검토
- 중요한 내용이 빠지거나 지나치게 단순화된 부분이 없는지 확인
- 과제의 주제·목적·분량·형식에 맞게 내용을 다시 구성
- 이해하지 못한 문장이나 근거를 확인하지 않은 내용을 그대로 사용하지 않기
예) 과제 주제에 대한 개요를 AI에게 요청하면 빠르게 목차와 핵심 내용을 얻을 수 있으나, 제시된 통계·사례·개념이 실제 자료와 일치하는지 확인하고 수업에서 다룬 내용과 연결하여 자신의 설명으로 다시 구성할 필요가 있음
---
## 3.2 업무에서는 ‘자동화’와 함께 ‘검토와 책임’의 비중이 커짐
업무 환경에서도 AI는 이메일과 보고서 초안 작성, 회의 내용 요약, 고객 문의 분류, 자료 검색, 데이터 분석 보조, 아이디어 정리 등 다양한 작업을 지원할 수 있음. 특히 반복적이고 형식이 비교적 명확한 작업에서는 처리 시간을 줄이고 여러 대안을 빠르게 만들어 줌
그러나 업무 결과는 실제 고객·조직·의사결정에 영향을 줄 수 있기 때문에 단순히 AI가 만든 결과를 빠르게 사용하는 것보다 결과가 업무 맥락에 적절한지 확인하는 과정이 중요
- 수치·이름·날짜·정책과 같은 사실 정보가 정확한지 확인
- 회사의 상황과 고객의 요구를 제대로 반영했는지 검토
- 개인정보·기밀정보가 AI나 외부 서비스에 불필요하게 입력되지 않았는지 확인
- 표현이 지나치게 단정적이거나 특정 집단에 불리하지 않은지 검토
- 중요한 의사결정에서는 AI의 제안을 하나의 참고 자료로 활용하고 다른 근거와 함께 판단
예) AI가 고객에게 보낼 답변 초안을 빠르게 작성할 수 있지만, 실제 환불 정책·고객 상황·회사 표현 기준을 잘못 반영하면 문제가 발생할 수 있음. 따라서 담당자는 초안을 검토하고 필요한 정보를 확인한 뒤 최종 답변을 결정해야 함. 이러한 활용의 가치는 반복 작업에 사용하는 시간을 줄이고 사람이 더 중요한 판단·조정·의사결정에 집중할 수 있도록 하는 데 있음
개인정보와 보안을 다루는 구체적인 기준과 안전한 처리 원칙은 7주차에서 더 자세히 다룸
---
## 3.3 일상에서는 ‘추천받는 사람’에서 ‘선택을 판단하는 사람’으로
일상에서는 검색·추천·쇼핑·이동 경로처럼 AI와 알고리즘이 정리한 선택지를 자연스럽게 이용함. 이러한 기능은 많은 정보 가운데 필요한 선택지를 빠르게 좁혀 주지만, 최종 선택은 사용자가 자신의 목적과 상황을 고려해 결정해야 함
일상에서 사람의 역할은 추천을 그대로 따르거나 거부하는 것이 아니라 추천된 결과가 자신의 실제 목적과 상황에 적절한지 판단하는 것
- 추천된 상품이 가격·품질·필요에 맞는지 비교
- 내비게이션의 추천 경로가 현재 일정이나 상황에 적절한지 판단
- 건강·금융·진로처럼 영향이 큰 정보는 추가 자료와 전문적인 근거를 확인
- 공유할 정보는 사실 여부와 출처를 확인
예) 동영상 플랫폼에서 건강 정보가 반복해서 추천되더라도 추천 횟수 자체가 의학적 신뢰성을 의미하지 않음. 중요한 판단이라면 공식 기관이나 전문 자료를 추가로 확인해야 함
즉 AI가 포함된 일상에서 디지털 리터러시는 추천된 선택지를 이해하고 자신의 기준으로 최종 선택을 완성하는 능력과 연결됨
---

## 3.5 종합 사례 : AI를 활용해 발표 과제를 준비한다면
**① 문제와 필요한 정보를 먼저 정함**
AI나 검색을 사용하기 전에 발표의 주제·목적·대상과 필요한 자료를 먼저 정함
- 발표에서 설명해야 할 핵심 질문을 정리
- 공식 자료·기사·통계 등 필요한 출처를 확보
- 작성자·작성 시점·근거를 비교해 사용할 자료를 선택
**② AI를 탐색과 정리의 보조 도구로 활용**
AI는 확보한 자료를 이해하고 발표 구조를 정리하는 보조 도구로 활용할 수 있음
- 어려운 개념을 쉬운 표현으로 다시 설명하도록 요청
- 자료의 핵심을 정리하거나 발표 목차의 초안을 작성
- AI가 제시한 사실·수치·사례는 원자료와 비교해 확인
AI가 만든 결과는 학습된 패턴을 이용한 것이므로, 문장이 자연스럽다는 이유만으로 정확성과 출처까지 신뢰할 수는 없음
**③ 자료를 자신의 결과물로 재구성**
검색과 AI를 통해 얻은 정보를 그대로 붙이는 것이 아니라 발표 목적과 청중에 맞게 선택하고 재구성
- 핵심 주장과 근거의 관계가 분명한지 확인
- 이미지·문장·통계 등을 사용할 때 출처와 권리를 확인
- 자신이 이해하고 설명할 수 있는 표현으로 다시 작성
**④ 최종 결과는 사람이 검토하고 결정**
발표 직전에는 완성된 결과가 정확하고 적절한지를 기준으로 확인
- 발표자가 각 내용을 이해하고 설명할 수 있는가
- 사실과 수치의 근거를 확인할 수 있는가
- 내용과 자료 사용이 적절하며 최종 결과에 책임질 수 있는가
AI는 자료를 찾고 정리하고 초안을 만드는 과정을 지원하지만, 문제를 정하고 정보를 선택하고 결과를 검토하고 최종적으로 책임지는 과정은 사람이 수행
<callout icon="💡" color="blue_bg">
	AI 시대의 디지털 리터러시는 AI와 디지털 기술을 많이 사용하는 능력이 아니라, 도구가 제공한 결과가 어떻게 만들어졌는지 이해하고 필요한 정보를 확인하며 자신의 목적과 상황에 맞게 판단·수정·활용하는 능력
</callout>

<callout icon="📌" color="gray_bg">
	**학습 요약**
	- 인공지능은 사람이 정한 목적에 맞춰 데이터를 처리하고 학습된 패턴을 이용해 결과를 만드는 기술과 방법의 집합이며, 인식·분류·예측·추천·생성 등의 기능으로 다양한 서비스에 활용
	- AI가 결과를 만드는 기본 흐름은 입력 → 처리 → 결과이며, AI의 학습과 활용 과정에서는 데이터가 학습의 재료가 되고 알고리즘을 통해 패턴을 학습한 결과가 모델에 반영되어 새로운 입력에 대한 결과를 만듦
	- AI는 학습된 데이터와 계산 구조를 바탕으로 가능성이 높은 결과를 제시하지만 사람처럼 의미와 맥락을 이해하는 것은 아니므로, 정확성·적절성·공정성·책임이 필요한 상황에서는 사람의 검토와 최종 판단이 필요
	- 디지털 리터러시는 디지털 기술을 사용하는 능력을 넘어 정보를 탐색하고 이해·평가하며 목적에 맞게 생성·소통하고 안전하고 책임 있게 활용하는 종합적인 역량
	- 디지털 환경에서는 검색·추천·SNS·광고 등에 알고리즘과 AI가 개입해 사람마다 보이는 정보와 선택지가 달라질 수 있으므로, 정보가 어떤 기준으로 제시되었는지 살펴보고 다른 출처와 관점을 확인하는 태도가 중요
	- AI가 학습·업무·일상에 널리 활용될수록 사람에게는 문제와 목적을 정하고 필요한 정보와 도구를 선택하며, AI와 디지털 서비스가 제시한 결과를 검토·수정하고 최종 사용에 책임지는 역할이 더욱 중요
</callout>
