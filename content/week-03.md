## 🎯 학습 목표
1. 정보 탐색 목적에 맞는 질문과 검색 전략을 설계할 수 있다
2. 1차 자료(Primary Source)·2차 자료(Secondary Source)·3차 자료(Tertiary Source)를 구분하고 출처의 신뢰도를 평가할 수 있다
3. 측면 읽기(Lateral Reading)와 교차검증(Cross-Verification)을 활용해 주장과 근거를 확인할 수 있다
4. 가짜 정보의 유형을 구분하고 팩트체크(Fact-Checking) 절차를 실제 사례에 적용할 수 있다
5. 디지털 윤리와 온라인 에티켓을 바탕으로 정보를 책임 있게 공유하고 잘못된 정보를 정정할 수 있다

</callout>

# 1️⃣ 1교시 \| 디지털 정보 탐색과 평가
---
## 1. 정보 탐색은 질문 설계에서 시작
디지털 정보 탐색은 검색창에 단어를 입력하는 것보다 무엇을 알고 싶은지 먼저 분명히 하는 과정이 중요
막연한 질문은 관련 없는 결과를 늘리고, 결론을 미리 정한 질문은 반대 근거와 예외를 놓치게 할 수 있음
### 1.1 탐색 질문의 구성
좋은 탐색 질문은 조사 범위와 필요한 근거를 분명하게 만드는 기준
- **주제**: 무엇을 조사하는지
- **대상**: 개인·집단·지역·산업 등 누구를 다루는지
- **기간**: 최신 정보인지 특정 시기의 변화인지
- **관점**: 효과·위험·비용·윤리·정책 중 무엇을 확인할지
- **자료 유형**: 통계·논문·법령·정책·보도자료·사례 중 어떤 근거가 필요한지
- **활용 목적**: 과제·발표·비교·의사결정 중 어디에 사용할지
- **좋지 않은 질문 예시**: “AI는 좋은가?”
- **개선된 질문 예시**: “2024년 이후 대학생 글쓰기 수업에서 생성형 AI 활용이 학습 효과와 과제 신뢰성에 어떤 영향을 주었는가?”
- **이해 포인트**: 좋은 검색 결과는 좋은 질문에서 시작
---
### 1.2 질문을 검색 가능한 요소로 분해
긴 질문을 핵심 개념으로 나누면 검색어를 조합하고 수정하기 쉬움
- **핵심 개념 추출**: 대학생, 생성형 AI, 글쓰기, 학습 효과
- **동의어 탐색**: 생성형 AI ↔ 생성 AI ↔ Generative AI
- **대상 확장**: 대학생 ↔ 고등교육 ↔ 학습자
- **자료 유형 추가**: 논문, 보고서, 통계, 정책
- **기간 추가**: 최근 2년, 특정 연도 이후
- **탐색 방식**: 결과를 확인하며 개념을 추가하거나 제외하는 반복 검색
- **이해 포인트**: 한 번에 완벽한 검색어를 만드는 것보다 검색 결과를 보며 질문을 정교화하는 과정이 중요
---
### 1.3 질문에 필요한 근거 수준 결정
모든 질문이 같은 수준의 근거를 요구하는 것은 아님
- **개념 확인**: 교과서·백과사전·기관 설명 자료로 시작 가능
- **현재 정책 확인**: 법령·공식 공지·정부 자료 우선
- **통계 확인**: 통계 생산 기관의 원자료와 조사 설명 확인
- **연구 결과 확인**: 논문 원문과 연구 방법 확인
- **생활 정보 확인**: 여러 출처를 비교하고 최신성·이해관계 확인
- **예시**: “이번 학기 학교의 생성형 AI 과제 규정”을 확인할 때 개인 블로그보다 학교 공식 공지가 우선
- **이해 포인트**: 질문의 중요성과 오류 비용이 클수록 더 직접적이고 책임 있는 근거가 필요
---
## 2. 검색 전략과 검색 도구 활용
검색은 한 번의 입력으로 정답을 얻는 행동이 아니라 결과를 보며 검색어와 자료 유형을 조정하는 반복 과정
검색 결과 상단에 있다는 사실과 신뢰도가 높다는 판단은 서로 다른 문제
### 2.1 핵심 검색 연산자
검색 연산자는 필요한 자료 범위를 좁히는 기능적 문법
- **정확한 구문**: `"디지털 리터러시"`처럼 동일한 구문을 중심으로 검색
- **제외 검색**: `AI 교육 -광고`처럼 특정 단어가 포함된 결과 제외
- **사이트 제한**: `site:go.kr`, `site:ac.kr`처럼 특정 도메인 안에서 검색
- **파일 형식 제한**: `filetype:pdf`로 보고서·정책 문서 중심 검색
- **대체 표현**: `청소년 OR 대학생`처럼 여러 표현을 함께 검색
- **조합 예시**: `"생성형 AI" 대학생 학습 효과 filetype:pdf`
- **주의점**: 검색 연산자는 자료를 찾는 효율을 높일 뿐 자료의 신뢰도를 자동으로 보장하지 않음
---
### 2.2 검색 결과 화면 읽기
검색 결과를 열기 전에도 제목·주소·기관·날짜·설명문을 통해 자료의 성격을 1차 판단 가능
- **도메인**: 정부·대학·기업·언론·개인 사이트 등 책임 주체 확인
- **제목**: 과장·공포·분노를 유도하는 표현 여부 확인
- **날짜**: 최신성이 중요한 주제인지 판단
- **설명문**: 검색어와 실제 문서 내용이 연결되는지 확인
- **광고 표시**: 광고·후원 콘텐츠인지 확인
- **이해 포인트**: 첫 번째 검색 결과라는 이유만으로 가장 좋은 근거가 되는 것은 아님
---
### 2.3 검색 추천과 개인화의 영향
검색 결과와 추천 콘텐츠는 검색어뿐 아니라 서비스 정책·지역·언어·사용 기록 등의 영향을 받을 수 있음
- **개인화**: 이전 관심사와 비슷한 결과가 반복 노출될 가능성
- **확증편향**: 이미 믿는 내용을 강화하는 자료만 선택적으로 찾는 경향
- **확인 방법**: 반대 관점의 검색어 사용, 다른 검색엔진 비교, 공식 기관·학술 데이터베이스 직접 검색
- **예시**: “AI 교육 효과 연구”와 “AI 교육 위험 연구”를 각각 검색해 결과 비교
- **이해 포인트**: 화면에 보이는 검색 결과는 현실의 모든 정보를 그대로 나열한 목록이 아님
---
### 2.4 검색 도구 선택
찾으려는 정보에 따라 적합한 검색 공간이 다름
- **일반 검색엔진**: 주제 개요와 관련 용어 파악
- **학술 데이터베이스**: 연구논문과 학술 근거 탐색
- **정부·공공기관 사이트**: 정책·법령·통계·공식 발표 확인
- **기관 내부 검색**: 대학·기업·단체의 공지와 규정 확인
- **뉴스 검색**: 사건의 시간 흐름과 다양한 보도 비교
- **이해 포인트**: 검색 도구를 바꾸는 것만으로도 같은 질문에 접근하는 근거의 종류가 달라짐

## 3. 자료 유형과 원출처 추적
자료 유형을 구분하면 탐색을 시작할 자료와 최종 근거로 사용할 자료를 구별하기 쉬움
### 3.1 1차 자료(Primary Source)
정보 생산자가 직접 작성·수집·발표한 원자료
- **대표 자료**: 정부 통계 원문, 연구논문 원문, 법령, 판결문, 기관 공식 발표, 원본 데이터, 인터뷰 원문
- **장점**: 조사 조건·단위·방법·예외를 직접 확인 가능
- **예시**: 기사에 “청년 실업률 8%”가 나오면 통계 생산 기관의 원자료에서 기준 시점과 정의 확인
- **주의점**: 1차 자료도 조사 설계·표본·측정 방식의 한계를 가질 수 있음
- **이해 포인트**: 원출처는 근거의 출발점을 직접 확인하기 위한 자료
---
### 3.2 2차 자료(Secondary Source)
1차 자료를 해석·비교·요약한 자료
- **대표 자료**: 기사, 해설 보고서, 리뷰 논문, 전문 분석 글
- **장점**: 복잡한 원자료의 의미와 맥락을 빠르게 이해하는 데 유용
- **위험**: 요약 과정에서 조건·예외·한계가 빠질 가능성
- **활용 방법**: 배경 이해에 활용한 뒤 중요한 수치와 주장은 원자료까지 추적
- **예시**: 경제 기사에서 현황 파악 → 공식 통계표에서 숫자 확인
---
### 3.3 3차 자료(Tertiary Source)
여러 자료를 다시 요약해 개괄적으로 정리한 자료
- **대표 자료**: 백과사전형 정리, 카드뉴스, 입문형 설명 페이지, 요약 콘텐츠
- **장점**: 처음 접하는 주제의 핵심 개념과 검색어 파악에 유용
- **한계**: 원근거와 세부 조건이 생략될 가능성
- **활용 방법**: 최종 증거보다 탐색 시작점과 관련 용어 확인에 활용
- **이해 포인트**: 자료 유형마다 잘하는 역할이 다름
---
### 3.4 원출처 추적
기사·게시물·카드뉴스에 등장하는 중요한 주장과 수치를 처음 생성한 자료까지 따라가는 과정
- **1단계**: 현재 자료가 인용한 기관·논문·보고서 확인
- **2단계**: 링크 또는 문서명을 이용해 원문 이동
- **3단계**: 원문에서 실제 문장·표·수치 확인
- **4단계**: 날짜·단위·대상·조건 확인
- **5단계**: 현재 자료가 원문의 의미를 정확하게 전달했는지 비교
- **주의점**: 여러 기사가 같은 보도자료 하나를 인용하면 독립적인 여러 근거가 아니라 하나의 원자료가 반복된 것일 수 있음
---
## 4. 출처 신뢰도 평가
신뢰도 평가는 사이트의 디자인이나 유명세보다 누가 만들었는지, 무엇을 근거로 했는지, 현재도 유효한지, 어떤 목적으로 제시됐는지를 함께 확인하는 과정
### 4.1 작성자와 책임 주체
- **확인**: 작성자 이름, 소속, 전문성, 공식 발행 여부, 연락 가능한 책임 주체
- **기관 자료**: 같은 기관 안에서도 공식 보고서와 홍보 게시물의 근거 수준은 다를 수 있음
- **익명 자료**: 중요한 판단의 단독 근거로 사용하기 어려움
- **예시**: 의료 정보는 개인 경험담보다 의료기관·학술자료 등 전문성과 책임 주체가 확인되는 자료를 우선 검토
- **이해 포인트**: 누가 말했는지 확인하는 것은 신뢰도 평가의 시작점
---
### 4.2 근거의 질
주장의 신뢰도는 출처 이름만 아니라 실제로 어떤 근거가 제시됐는지에 따라 달라짐
- **확인**: 데이터·연구·공식 기록·직접 인용 등 구체적 근거 존재 여부
- **원문 연결**: 근거를 직접 확인할 수 있는 링크나 문서 정보 존재 여부
- **표본과 방법**: 조사 대상과 방법이 주장 범위에 적절한지 확인
- **비교**: 개인 경험 한 건과 체계적으로 수집된 자료의 증거 수준 구분
- **이해 포인트**: 신뢰할 만한 기관의 자료라도 근거가 약한 개별 주장까지 자동으로 신뢰할 수 있는 것은 아님
---
### 4.3 최신성
정보가 만들어진 시점과 현재까지 유효한지를 확인하는 기준
- **변화가 빠른 정보**: 정책, 법률, 소프트웨어 기능, 가격, 서비스 이용 조건
- **비교적 안정적인 정보**: 역사적 사건, 기본 개념 등
- **확인**: 게시일뿐 아니라 수정일·적용일·기준일 확인
- **예시**: 3년 전 서비스 이용약관을 현재 정책처럼 사용하지 않기
- **이해 포인트**: 오래된 자료라는 이유만으로 틀린 것은 아니지만 현재 질문에 적합한지 별도로 판단
---
### 4.4 목적과 이해관계
정보가 왜 만들어졌는지를 확인하면 표현 방식과 생략 가능성을 이해하는 데 도움
- **가능한 목적**: 정보 제공, 연구, 홍보, 판매, 정치적 설득, 관심 유도
- **광고·후원**: 이해관계가 공개되어 있는지 확인
- **감정 자극**: 공포·분노·긴급성을 과도하게 강조하는지 확인
- **예시**: 제품을 판매하는 회사의 자체 조사 결과는 조사 방법과 함께 이해관계도 확인
- **이해 포인트**: 이해관계가 있다고 무조건 틀린 것은 아니지만 독립 근거와의 비교가 중요
---
### 4.5 맥락 확인
실제 자료도 일부만 잘라 사용하면 원래 의미와 다른 정보가 될 수 있음
- **확인**: 앞뒤 문장, 전체 표, 원 영상, 조사 기간, 대상 집단
- **수치 맥락**: 비율의 분모와 비교 기준 확인
- **인용 맥락**: 발언이 질문·반론·가정 중 어떤 상황에서 나온 것인지 확인
- **이해 포인트**: 사실 여부와 맥락의 정확성은 함께 확인해야 함
---
## 5. 측면 읽기와 자료 비교
측면 읽기(Lateral Reading)는 한 페이지 안의 정보만 오래 살펴보기보다 새 탭을 열어 사이트·작성자·주장을 외부 자료와 비교하는 검증 방식
### 5.1 측면 읽기의 기본 절차
- **1단계**: 현재 페이지의 작성자와 기관 확인
- **2단계**: 사이트 밖에서 기관명·작성자명 검색
- **3단계**: 독립적인 자료가 해당 기관을 어떻게 설명하는지 확인
- **4단계**: 핵심 주장과 수치를 원출처에서 확인
- **5단계**: 다른 신뢰할 수 있는 자료와 비교
- **이해 포인트**: 사이트가 스스로 소개하는 정보와 외부에서 확인되는 평판·근거를 함께 보는 방식
---
### 5.2 같은 주장에 대한 자료 비교
같은 주장을 다루는 자료를 비교할 때는 일정한 기준으로 확인하면 판단이 쉬움
- **작성 주체**: 누가 만들었는지
- **원출처**: 최초 자료를 직접 확인할 수 있는지
- **근거**: 데이터·연구·기록이 제시되는지
- **최신성**: 기준일이 현재 질문에 적합한지
- **맥락**: 조건·예외·불확실성을 함께 설명하는지
- **예시**: 동일 통계를 다룬 정부 원자료·신문 기사·SNS 카드뉴스를 나란히 놓고 생략된 정보를 비교
---
### 5.3 독립된 근거인지 확인
출처 수가 많아 보여도 실제로는 모두 같은 원자료를 반복 인용할 수 있음
- **확인**: 각 자료가 서로 다른 데이터·연구·취재를 사용했는지
- **주의점**: 기사 10개가 같은 보도자료 하나를 인용하면 근거가 10개가 된 것은 아님
- **활용**: 서로 다른 기관·방법·자료에서 같은 결론이 확인되는지 비교
- **이해 포인트**: 교차검증은 검색 결과 개수보다 근거의 독립성이 중요
---
## 6. 탐색 기록과 검색 실패 점검
좋은 정보 탐색은 결과만 남기는 것이 아니라 어떤 검색어와 자료를 사용했고 왜 선택했는지 간단히 기록하는 과정도 포함
### 6.1 탐색 기록
- **검색어**: 어떤 검색어와 연산자를 사용했는지
- **자료명**: 확인한 문서·기사·논문
- **출처 유형**: 1차·2차·3차 자료 중 어디에 해당하는지
- **판단**: 신뢰할 만한 이유와 주의할 점
- **활용**: 어떤 주장이나 문장에 사용할지
- **효과**: 같은 검색 반복 감소, 출처 누락 방지, 팀 작업에서 조사 과정 공유
---
### 6.2 검색 실패 유형
- **너무 넓은 검색**: 일반론과 광고 결과가 과도하게 등장
- **너무 좁은 검색**: 필요한 근거가 거의 나오지 않음
- **결론형 검색**: 원하는 결론과 같은 자료만 반복 확인
- **최신성 누락**: 오래된 정책·통계를 현재 정보처럼 사용
- **원출처 미확인**: 기사·SNS 요약만 반복 인용
- **개선 방법**: 질문 범위·기간·동의어·자료 유형·기관 범위를 다시 조정
---
### 6.3 탐색을 멈출 기준
검색을 오래 한다고 항상 더 좋은 결과가 되는 것은 아님
- 핵심 주장에 필요한 원자료를 확보했는지
- 서로 독립적인 근거를 비교했는지
- 반대 또는 예외 자료를 확인했는지
- 최신성과 조건을 확인했는지
- 더 검색해도 같은 근거만 반복되는지
- **이해 포인트**: 충분한 근거를 확보한 뒤 판단 단계로 넘어가는 것도 정보 탐색 능력의 일부
---
# 2️⃣ 2교시 \| 가짜 정보·팩트체크와 디지털 윤리
---
## 1. 가짜 정보와 오정보 이해
잘못된 정보는 내용의 오류뿐 아니라 제작 의도와 맥락에 따라 서로 다른 형태로 나타남
### 1.1 잘못된 정보의 주요 유형
- **오정보(Misinformation)**: 틀린 정보를 사실이라고 믿고 의도 없이 공유하는 경우
- **허위정보(Disinformation)**: 속이거나 영향을 주기 위해 의도적으로 거짓 정보를 만드는 경우
- **맥락 왜곡**: 실제 사진·수치·발언을 다른 상황의 자료처럼 사용하는 경우
- **과장 정보**: 일부 사실을 지나치게 확대해 전체 사실처럼 표현하는 경우
- **풍자·패러디**: 본래 의도와 다르게 실제 뉴스처럼 오해될 가능성이 있는 콘텐츠
- **이해 포인트**: “거짓인가?”뿐 아니라 “어떤 방식으로 잘못 전달됐는가?”를 확인
---
### 1.2 가짜 정보가 확산되는 이유
- **감정 자극**: 분노·공포·놀라움이 강한 콘텐츠의 빠른 공유
- **확증편향**: 기존 생각과 일치하는 정보의 쉬운 수용
- **속도 경쟁**: 확인보다 빠른 전달을 우선하는 환경
- **출처 생략**: 캡처·재편집 과정에서 원문 정보 소실
- **알고리즘 추천**: 반응이 많은 콘텐츠가 더 넓게 노출될 가능성
- **생성형 AI**: 그럴듯한 텍스트·이미지·음성을 빠르게 대량 생성할 수 있는 환경
- **이해 포인트**: 정보의 확산 속도와 사실성은 별개의 기준
---
### 1.3 의심 신호
의심 신호는 거짓이라는 확정 판정이 아니라 추가 검증이 필요하다는 표시
- 출처가 없거나 모호함
- “지금 당장 공유”처럼 긴급한 행동 요구
- 지나치게 충격적인 제목
- 구체적인 수치가 있지만 원자료가 없음
- 캡처 이미지로만 출처 제시
- 날짜·장소·작성자가 불명확함
- **이해 포인트**: 의심 신호가 보이면 공유보다 검증을 먼저 선택
---
## 2. 팩트체크의 대상과 판단
팩트체크는 모든 문장을 단순히 참·거짓으로 나누는 것이 아니라 검증 가능한 주장을 찾아 근거와 맥락을 확인하는 과정
### 2.1 검증 가능한 주장
- **검증 가능**: 날짜, 수치, 인물의 발언, 정책 내용, 사건 발생 여부
- **의견**: 개인의 가치 판단이나 선호
- **예측**: 미래에 대한 전망
- **혼합형**: 사실과 의견이 함께 포함된 문장
- **예시**: “대학생의 80%가 매일 생성형 AI를 사용한다”는 조사 근거를 확인할 수 있는 사실 주장
- **이해 포인트**: 먼저 무엇을 검증할 수 있는 문장인지 구분해야 함
---
### 2.2 주장을 작은 단위로 분해
한 문장 안에 여러 사실이 섞이면 각각 분리해서 검증
- 누가 말했는가
- 언제 발표됐는가
- 어떤 집단을 대상으로 했는가
- 수치가 정확한가
- 원자료가 존재하는가
- 원자료가 실제로 같은 의미를 말하는가
- **예시**: “정부가 모든 대학의 AI 사용을 금지했다”는 주체·범위·정책 존재 여부·적용 시점을 각각 확인
---
### 2.3 팩트체크 판단 표현
증거가 불충분한 상황에서 억지로 참·거짓을 결정하지 않는 태도가 중요
- **확인됨**: 신뢰할 수 있는 원자료와 독립 근거가 일치
- **부분 확인**: 일부는 맞지만 범위·수치·조건이 과장 또는 누락
- **맥락 필요**: 사실 자체는 맞지만 사용된 맥락이 원래 의미와 다름
- **근거 부족**: 확인 가능한 자료가 충분하지 않음
- **거짓**: 신뢰할 수 있는 근거와 명확하게 충돌
- **이해 포인트**: 불확실성을 정확하게 표시하는 것도 팩트체크 결과
---
## 3. 교차검증과 원맥락 확인
교차검증은 서로 독립적인 자료를 비교해 하나의 주장에 대한 근거를 확인하는 과정
### 3.1 독립적인 출처 비교
- 같은 자료를 그대로 재전송한 여러 게시물은 독립 근거가 아님
- 서로 다른 기관·취재·연구에서 같은 사실이 확인되는지 검토
- 기사 여러 개보다 기사들이 어떤 원자료를 사용했는지 확인
- 공식 발표만 있는 경우 이해관계가 다른 독립 자료도 함께 검토
- **이해 포인트**: 출처의 수보다 독립성과 근거의 질이 중요
---
### 3.2 원맥락 추적
발언·사진·영상·통계가 처음 제시된 상황을 찾아 현재 설명과 비교
- **발언**: 전체 인터뷰·연설에서 앞뒤 내용 확인
- **사진**: 최초 게시 시점과 장소 확인
- **영상**: 원본 영상의 앞뒤 장면 확인
- **통계**: 조사표·보고서의 정의와 주석 확인
- **이해 포인트**: 실제 자료도 다른 맥락에 붙이면 잘못된 정보가 될 수 있음
---
### 3.3 숫자와 그래프 확인
수치는 객관적으로 보이지만 기준과 단위에 따라 의미가 달라질 수 있음
- 분모가 무엇인지
- 조사 대상이 누구인지
- 조사 기간이 언제인지
- 변화율과 절대값을 혼동하지 않았는지
- 그래프 축이 차이를 과장하지 않는지
- 원표와 현재 그래프의 숫자가 일치하는지
- **연결**: 통계와 시각화의 자세한 해석은 6주차에서 확장
---
## 4. 이미지·영상·음성 검증
시각·음성 콘텐츠는 강한 사실감을 주기 때문에 출처와 맥락을 별도로 확인할 필요
### 4.1 이미지 검증
- 최초 게시 계정과 게시 시점 확인
- 사진 속 장소·날씨·간판·표지판 등 맥락 단서 확인
- 동일 이미지가 과거 다른 사건에 사용됐는지 확인
- 이미지 검색 등을 이용해 이전 게시물 탐색
- 캡처된 문서라면 기관 공식 원문 존재 여부 확인
- **이해 포인트**: 실제 사진도 잘못된 설명과 결합하면 허위 정보 역할을 할 수 있음
---
### 4.2 영상과 음성 검증
- 전체 영상이 아닌 짧은 편집본인지 확인
- 음성과 입 모양·장면 전환이 자연스러운지 확인
- 원본 게시자와 최초 업로드 시점 확인
- 발언의 앞뒤 맥락 확인
- 다른 신뢰할 수 있는 자료에서도 같은 사건이 확인되는지 비교
- **주의점**: 편집 흔적이 보이지 않는다는 사실만으로 진짜라고 확정할 수 없음
---
### 4.3 생성형 AI 콘텐츠 검증
생성형 AI로 만든 콘텐츠는 자연스럽고 사실적으로 보일 수 있지만 실제 사건의 증거와는 구분해야 함
- 출처와 제작 경위 확인
- 실제 인물·장소·사건을 표현했다면 원자료 대조
- 이미지 속 글자·표지·물체 구조 등 오류 가능성 확인
- AI 생성 여부 표시가 있는지 확인
- **이해 포인트**: “그럴듯해 보인다”는 사실성의 근거가 아님
---
## 5. 팩트체크 6단계
복잡한 정보를 검증할 때 일정한 순서를 사용하면 누락을 줄일 수 있음
### 5.1 기본 절차
1. **주장 분리**: 무엇이 사실 주장인지 표시
2. **출처 확인**: 누가 언제 어디에서 만들었는지 확인
3. **원자료 추적**: 통계·문서·영상·발언의 최초 자료 확인
4. **교차검증**: 독립적인 자료와 비교
5. **맥락 확인**: 대상·기간·조건·앞뒤 내용 확인
6. **판단 기록**: 확인됨·부분 확인·맥락 필요·근거 부족·거짓 등으로 이유와 함께 정리
- **이해 포인트**: 검색 결과가 많다는 이유보다 원자료와 독립 근거가 연결되는지가 중요
---
### 5.2 생활 사례 \| 건강정보 검증
SNS에서 “특정 음식이 감기를 하루 만에 치료한다”는 게시물을 본 상황
- **주장 분리**: 음식 섭취가 질병 치료 시간을 단축한다는 주장 확인
- **출처 확인**: 작성자가 의료기관·전문가·광고 계정인지 확인
- **원자료 추적**: 연구나 임상 근거가 제시되어 있는지 확인
- **교차검증**: 공신력 있는 의료기관과 복수의 연구 자료 비교
- **맥락 확인**: 예방·증상 완화·치료를 혼동하지 않았는지 확인
- **최종 판단**: 근거 수준에 따라 공유 여부 결정
- **주의점**: 건강·안전처럼 오류 비용이 큰 정보는 검증 수준을 더 높게 설정
---
## 6. 디지털 윤리의 기본
디지털 윤리는 온라인에서 할 수 있는 행동과 해야 하는 행동을 구분하고, 정보 이용이 다른 사람과 사회에 미치는 영향을 고려하는 기준
### 6.1 윤리적 판단 질문
정보를 게시·공유·편집하기 전에 다음 질문으로 판단 가능
- 이 정보는 충분히 확인됐는가
- 다른 사람에게 불필요한 피해를 줄 가능성이 있는가
- 일부만 잘라 원래 의미를 왜곡하지 않았는가
- 타인의 개인정보·명예·권리를 침해하지 않는가
- 광고·AI 생성·편집 사실처럼 알아야 할 정보를 숨기고 있지 않은가
- 오류를 발견했을 때 수정할 수 있는가
- **연결 기준**: 정확성·책임성·공정성·존중·투명성·피해 최소화
---
### 6.2 디지털 발자국(Digital Footprint)
온라인 활동 과정에서 남는 게시물·댓글·검색·공유·계정 활동 등의 기록
- 삭제한 게시물도 캡처·재공유로 남을 가능성
- 공개 범위가 바뀌거나 다른 맥락에서 다시 사용될 가능성
- 본인의 기록뿐 아니라 타인의 기록을 만들 때도 책임 필요
- **예시**: 친구 사진을 허락 없이 단체 채팅방에서 다른 SNS로 재공유
- **이해 포인트**: 게시 전에는 현재의 감정뿐 아니라 기록이 남을 가능성도 고려
---
### 6.3 권리와 안전의 연결
디지털 윤리는 개인정보·저작권·보안과 연결되어 작동
- 타인의 개인정보를 필요 이상으로 공개하지 않기
- 사진·글·음악을 사용할 때 권리와 출처 확인
- 사적인 대화 캡처를 허락 없이 공개하지 않기
- 민감한 정보를 생성형 AI 서비스에 무분별하게 입력하지 않기
- **연결**: 개인정보·저작권·보안의 구체적인 보호 방법은 7주차에서 확장
---
## 7. 온라인 에티켓
온라인 에티켓은 디지털 공간에서 서로의 시간·감정·맥락·권리를 존중하기 위한 소통 규칙
### 7.1 텍스트 소통
문자 기반 소통은 표정과 억양이 보이지 않아 의도와 다르게 받아들여질 가능성
- 요청의 목적과 마감 시점을 분명하게 작성
- 상대가 즉시 답해야 한다고 가정하지 않기
- 비판은 사람보다 행동·주장·결과에 초점
- 공개 공간과 개인 대화의 범위 구분
- **표현 비교**: “왜 아직 안 했어요?”보다 “현재 진행 상황과 예상 완료 시점을 알려주세요”처럼 필요한 정보를 명확하게 요청
---
### 7.2 댓글과 온라인 토론
- 주장과 사람을 구분해서 비판
- 상대의 말을 임의로 축약하거나 왜곡하지 않기
- 출처가 필요한 주장에는 근거 제시
- 비꼼·조롱·혐오 표현보다 확인 가능한 쟁점 중심으로 소통
- **표현 비교**: “틀렸다”보다 “이 주장은 어떤 근거와 기준을 사용했는지 확인이 필요하다”처럼 논점을 구체화
- **이해 포인트**: 동의하지 않는 상황에서도 근거와 존중을 함께 유지할 수 있음
---
### 7.3 단체 채팅과 협업 공간
- 업무와 관계없는 반복 메시지 최소화
- 필요한 사람만 태그하거나 호출
- 개인 정보와 내부 자료의 공개 범위 확인
- 수정·삭제가 필요한 경우 변경 내용을 명확하게 알림
- 파일명·버전·담당자 등 협업 정보를 일정한 방식으로 관리
- **이해 포인트**: 온라인 협업의 에티켓은 친절함뿐 아니라 정보 혼란과 불필요한 시간을 줄이는 기준
---
## 8. 책임 있는 정보 공유
정보를 공유하는 순간 사용자는 단순 소비자가 아니라 정보 유통 과정의 참여자가 됨
### 8.1 공유 전 확인
- 원출처를 확인했는가
- 제목과 본문 내용이 일치하는가
- 날짜와 현재 상황이 맞는가
- 수치와 인용이 원문과 일치하는가
- 불확실한 내용을 확정적으로 표현하지 않았는가
- 개인정보·권리 침해 가능성이 없는가
- **원칙**: 확신이 없을 때는 빠른 공유보다 보류와 추가 확인을 선택
---
### 8.2 잘못 공유한 정보의 정정
잘못된 정보를 발견했다면 단순 삭제보다 이미 본 사람에게 정정 사실이 전달되도록 하는 것이 중요
- 잘못된 부분이 무엇인지 명확하게 표시
- 수정된 정보와 근거 제시
- 같은 채널에서 정정해 기존 수신자가 볼 수 있도록 함
- 다른 사람을 공격하기보다 정보 자체의 오류를 중심으로 설명
- **예시**: “앞서 공유한 공지 이미지는 과거 자료였으며 현재 규정은 학교 공식 공지에서 확인한 내용으로 정정합니다”
---
### 8.3 불확실성 표시
모든 정보가 즉시 확정 가능한 것은 아님
- “현재 확인된 범위에서는”
- “공식 발표 추가 확인 필요”
- “원자료를 찾지 못해 확인 불가”
- “일부 내용만 확인됨”
- **이해 포인트**: 불확실성을 표시하는 것은 약한 표현이 아니라 정보의 상태를 정확하게 전달하는 방법
---
## 9. 종합 사례 \| “학교가 생성형 AI 사용을 전면 금지했다”는 공지 이미지
SNS와 단체 채팅방에서 학교 로고가 들어간 공지 이미지가 빠르게 공유되고 있으며 “이제 모든 수업에서 생성형 AI 사용이 금지된다”는 설명이 함께 붙어 있는 상황
### 9.1 확인할 주장 분해
- 해당 이미지가 실제 학교 공지인지
- 공지가 현재 학기의 자료인지
- 모든 수업에 적용되는 규정인지
- 과제·시험·일부 교과목 중 특정 상황에만 적용되는지
- 학교 전체 정책인지 개별 수업의 안내인지
- **이해 포인트**: 하나의 이미지 안에서도 여러 주장을 분리해야 정확하게 검증 가능
---
### 9.2 정보 탐색
- 학교 공식 홈페이지와 공지 게시판에서 관련 정책 검색
- `site:` 검색을 이용해 학교 공식 도메인 안에서 관련 문서 탐색
- “생성형 AI”, “과제”, “학업윤리”, “사용 지침” 등 여러 검색어 조합
- 최근 날짜의 정책 문서와 FAQ 확인
- 검색 결과에서 비슷한 이름의 다른 학교·기관 자료가 섞이지 않았는지 확인
- **판단**: 검색 결과 상단의 게시물보다 실제 공식 원문과 최신 적용일을 우선 확인
---
### 9.3 출처 평가와 팩트체크
- 이미지의 최초 게시 계정과 게시 시점 확인
- 공식 기관 계정에 동일한 공지가 있는지 비교
- 이미지에 적힌 문서번호·담당 부서·날짜가 공식 문서와 일치하는지 확인
- “전면 금지”라는 표현이 원문에 실제로 있는지 확인
- 원문이 특정 시험·과제·교과목에만 적용되는지 맥락 확인
- 다른 공식 안내와 내용이 충돌하지 않는지 비교
- **판단 예시**: 실제 공지이지만 특정 시험에만 적용된다면 “전면 금지”는 맥락이 과장된 정보
---
### 9.4 이미지와 윤리적 공유 판단
- 학교 로고와 문서 형식만 보고 진짜라고 단정하지 않기
- 검증 전 “큰일 났다” 같은 감정적 표현을 붙여 재공유하지 않기
- 학생 이름·학번·단체 채팅 캡처 등 개인정보가 포함되어 있다면 제거
- 일부만 확인된 경우 확정적인 문구 사용하지 않기
- 잘못된 이미지라면 게시자를 공격하기보다 공식 원문과 차이를 근거로 정정
---
### 9.5 최종 공유 문안
검증 결과를 사실과 판단으로 나누어 전달
- **확인된 사실**: 공식 공지의 제목·날짜·적용 범위
- **잘못 전달된 부분**: “모든 수업 전면 금지”처럼 원문보다 확대된 표현
- **근거**: 학교 공식 공지 또는 담당 부서 안내
- **권장 표현 예시**: “공식 공지를 확인한 결과 생성형 AI 사용 제한은 특정 평가 상황에 적용됩니다. 모든 수업에서 전면 금지된 것은 아니므로 과목별 안내를 추가로 확인해야 합니다.”
- **전체 흐름**: 질문 설계 → 검색 → 원출처 확인 → 측면 읽기 → 교차검증 → 맥락 판단 → 윤리적 공유
